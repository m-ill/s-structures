# 탄성해석 설정 창과 탭 전환

탄성 탭 최초 진입 시 미완료 설정을 자동으로 열던 native-mode-change 처리에서 다른 탭 이탈은 처리하지 않아 창이 계속 남았다.

- 탭 진입은 설정 창을 자동으로 열지 않는다. 기존 기본설정·하중·조합 버튼과 API로 명시적으로 연다.
- 다른 탭으로 이동할 때 열려 있는 설정 창만 기존 close() 경로로 닫는다. 입력 초안을 읽고 유지하며 모델에 자동 적용하지 않는다.
- 비선형 작업 중 명시적으로 여는 하중·질량 편집 버튼 등은 유지한다.

브라우저에서 캐시를 우회한 새 로딩 후 모델링·비선형·메모 각각으로 이동과 복귀, 수동 열기·닫기, 프로젝트 ID 미적용 초안 보존을 확인했다. 모든 경우 통과했다. 로컬 재현 스크립트는 작업결과/elastic-tab-20260913/browser-check.js에 있다.
