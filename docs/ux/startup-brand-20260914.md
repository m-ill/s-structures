# 초기 로딩 화면 개선

- 기존 단색 준비 화면을 구조 프레임 안의 S 로고, 짙은 파란색 배경, 금색 경로 애니메이션으로 교체했다.
- SVG와 스타일은 HTML에 포함해 추가 이미지 요청 없이 첫 화면부터 표시한다.
- 실제 준비 완료 신호까지 기존 UI를 숨기는 게이트를 유지한다. 가짜 진행률이나 의도적인 대기 시간은 없다.
- 30초 이상 지연되거나 모듈 로딩에 실패하면 재시도를 제공한다. 실패하면 애니메이션을 정지한다.
- 모션 감소 설정에서는 애니메이션을 사용하지 않는다. 상태 문구와 JavaScript 비활성 안내를 유지한다.

## 확인

2026-09-14 Playwright에서 진입 모듈 요청을 보류/실패 처리하여 데스크톱 로딩, 390px 모바일 표시, 모션 감소, 정상 준비 완료 및 실패 후 재시도를 확인했다. `node tools/check-pages-preview.mjs` 필수 10개 검사 통과.

수치 해석과 설계 기능은 수정하지 않았다.
