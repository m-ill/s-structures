# 보고서 출력 일관성과 에이전트 시작 안내

## 변경

- UI와 WebMCP의 예비 검토 PDF를 `general-structural-review-v1` 공통 출력으로 변경했다. canvas·시스템 글꼴 측정 대신 내장 SStructuresSans의 글리프 폭으로 줄바꿈하고 검색 가능한 벡터 PDF를 생성한다. A4, 고정 여백, 페이지 번호, 부재별 검토 묶음, KDS 근거·미확인 사유를 보존한다.
- PDF 응답에 템플릿·렌더러·폰트 해시와 입력·결과·snapshot 해시를 기록한다. 최대 400쪽·32MiB 출력 제한을 유지한다. 기존 상세도 PDF는 별도 유형으로 유지한다.
- HTML 계산서·상세 보고서·한영 보고서·설계 검토 기록에도 공통 글꼴 참조를 적용했다. 수동 인쇄는 브라우저 설정 영향을 받을 수 있으므로 동일 양식의 기준 산출물은 공통 PDF다.
- 데스크톱 한영 보고서에는 글꼴 파일을 함께 저장하고 manifest에 해시를 남긴다. HTML에 로컬 절대 경로를 넣지 않으며, 데스크톱 렌더러는 글꼴 로딩 실패 시 대체 글꼴로 조용히 출력하지 않는다. 개인정보·경로 노출 검사와 원자적 게시 검사는 유지한다.
- 기존 한영 데스크톱 PDF 경로의 Windows 문자열 판정을 제거했다. 명시적인 qualification은 보존하고, 기본값은 실제 어댑터가 있으면 `READY`/산출물 검증 필요, 없으면 `BLOCKED`다. `READY`는 `releaseQualified:false`이며 구조설계 적합성 승인이 아니다. 공개 사이트의 공통 PDF는 Electron 어댑터를 요구하지 않는다.
- WebMCP의 등록 4개는 유지한다. 기능 카탈로그는 94개이며 `get_agent_start_context`를 추가했다. 검색 결과와 프로젝트 조회가 시작 안내를 가리킨다. 현재 모델 개수·입력 버전, 도구 선택 절차, 사람의 판단 경계, 공통 보고서 계약을 읽을 수 있다.
- 새 프로젝트 AGENTS.md와 보고서 지침에도 접속 시 조회와 보고서 생성 순서를 넣었다. 기존 사용자 지침을 자동 덮어쓰지 않는다. 웹페이지가 다른 AI 앱의 영구 기억이나 상위 지침을 수정하는 기능은 아니다. 호스트에 없는 도구를 설치하거나 권한·입력 검증 거부를 우회하지 않는다.

## 사용

연결된 에이전트에게 원하는 구조설계 작업을 요청한다. 사이트 도구를 조회하면 시작 안내를 발견할 수 있다. 안내에 따라 WebMCP를 우선 사용하고 화면·캡처는 브라우저 도구, 필요한 데스크톱 작업은 호스트에서 제공되는 컴퓨터 도구로 수행한다. 각 에이전트의 도구 지원·권한은 그대로 적용된다.

보고서는 기존 완료된 검토에 대해 `plan_report_export` → `start_report_export` → `export_report_pdf` 순서로 생성한다. 저장·복원한 보고서는 `open_report_artifact`로 핸들을 얻는다. 이 이름들은 `describe_sstructures_tool`을 조회한 뒤 반환된 `invokeWith` 채널로 호출한다. `export_design_drawings`의 상세도·수량·PDF 묶음은 별도 목적이다.

## 검증

- 테스트를 먼저 추가해 새 계약이 없는 상태의 실패를 확인했다.
- `tests/report-agent-portability.mjs`: 동일 합성 기록의 OS 식별값별 PDF 바이트 일치, 고정 SHA-256, 글꼴 임베딩, 실패 후 메모리 해제, 명시적 BLOCKED 보존, 시작 안내와 도구 크기 검사.
- `tests/p22-focused.mjs`: 기존 분석·복원·stale·메모리 경계와 보고서 변조 거부.
- Pages 필수 검사와 한영 렌더링·페이지 배치·UI/Agent 출력 관련 검사를 수행한다. 한영 글꼴 검사는 새 내장 글꼴 기준으로 갱신했다.
- Windows의 실제 브라우저에서 합성 PDF 2쪽, 검색 가능 상태와 자원 사용량 복귀를 확인했다. Poppler로 페이지를 렌더링하고 한글·여백·검토 항목의 페이지 나눔을 확인한다.
- 고정 fixture PDF SHA-256: `9aebd23cf01f4a850a1fa4768170e64d5eca547d58914f5a93dee87e3c235cda`. 배포 CI에서도 이 값을 검사한다.
- 실제 Mac 장치·Safari의 종합 시험과 실제 건물 재해석은 이번 범위가 아니다. 기존 결과와 기능을 보존하고 보고서·접속 경로를 수정했다.
