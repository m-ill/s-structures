# WP-03 설계모듈 실증

stage: V / milestone: P4-M3 / tickets: P4-T12~T16 / 크기: L
status: not-started

## Objective

P3-M17~M18(RC/철골/기초/접합 상세설계)을 proven으로 승격한다. 설계 검토값은 계산서에 실리는 값이므로 **케이스 전수가 E2(수계산 검증서)**를 요구한다. KDS 조항 번호 없는 검토식은 proven 불가.

## Scope

**In**: 수계산 검증서, 조항 registry 확정, limitation 문구 확정, 일람표 회귀 고정.
**Out**: 신규 검토 항목(비틀림 상세 등 확장), 배근도 생성.

## Preconditions

1. WP-01 Step 2 완료 권장 (부재력 demand의 기준값 신뢰 확보 후 설계값 검증이 유의미).
2. 예제집 선택 오너 승인 (R8): 제안 목록을 먼저 제출 — KDS 해설서 예제 / 콘크리트학회·강구조학회 예제집 / 대학 교재 중 확보 가능본.

## Work Breakdown

### Step 1. 검증서 골격 (T12 착수)
1. `docs/verification/DESIGN_MODULE_VERIFICATION.md` 생성 — 장 구성: RC 보 / RC 기둥 / RC 벽체 / RC 슬래브 / 철골 부재 / 가새·접합·base plate / 기초.
2. 케이스 표준 5열: 입력(재료·단면·하중) / 적용 조항(KDS 번호) / 손계산 전개 / 프로그램 값 / 오차.
3. 결정 대기 표 신설: 조항 해석이 갈리는 지점은 오너 결정 큐로 (R8 대응).

### Step 2. RC 검증 (T12)
| 모듈 | 케이스 (각 3+) | 핵심 대조값 |
| --- | --- | --- |
| 보 | 단철근/복철근/전단 스터럽 | 소요 As, φMn, Vs 간격 |
| 기둥 | PM 상관도 3점 (P0/Pb/M0) + 세장 확대 | 상관도 점, δ 계수 |
| 벽체 | pier PM + 면내전단 + 경계요소 판정 | φVn, 경계요소 필요성 |
| 슬래브 | 1방향 계수법 + 직접설계법 + 뚫림전단 | 배분 모멘트, φVc(뚫림) |

각 케이스를 `tests/p4-design-rc-handcalc.mjs`에 등재 (±1%).

### Step 3. 철골/기초 검증 (T13)
| 모듈 | 케이스 | 핵심 대조값 |
| --- | --- | --- |
| 압축재 | 세장비별 좌굴 (탄성/비탄성 경계 포함) | φPn |
| 휨재 | Lb 3구간 (소성/비탄성LTB/탄성LTB) | φMn, Cb |
| 조합력 | H1 상관 1축/2축 | 상관비 |
| 가새 | 인장(순단면/블록전단) + 압축 | 지배 한계상태 |
| 볼트/용접/BP | 표준 접합 각 1 | 설계강도 |
| 기초 | 편심 접지압 + 1방향/뚫림 + 매트 스트립 + 말뚝 반력 | 접지압 분포, φVc |

`tests/p4-design-steel-foundation-handcalc.mjs`.

### Step 4. 조항 registry 확정 (T14)
1. `src/standards/`의 조항 표를 실제 사용 검토식과 1:1 대조 — 누락 조항 보충, 버전(연도) 표기.
2. 계산서 각 검토 행에 조항 ID 출력 확인 (기존 trace 계약 활용) — 스냅샷 테스트.

### Step 5. Limitation 확정 (T15) + 승격 (T16)
1. 미검토 항목(비틀림 상세, 내진 특수상세 등) 문구를 계산서 장별로 확정, 스냅샷 테스트.
2. 대표건물 10종 일람표 재생성 → 회귀 고정. M17~M18 proven 전환.

## Deliverables

검증서(전 케이스 손계산 포함) / 테스트 2본 / 조항 registry 갱신 / 승격 커밋 2건.

## Acceptance Criteria

1. 케이스 최소 수 충족 (RC 12+, 철골·기초 12+), 전부 조항 번호 보유.
2. 오차 ±1% (반올림 규칙 명기).
3. 결정 대기 표 잔여 0 (오너 결정 완료).
4. 완성도 감사 M17~M18 = proven.

## Verification Procedure

`npm test` + 신규 테스트 2본. 문서 리뷰: 무작위 케이스 2건 손계산 재현.

## Risks & Rollback

R8(조항 판단 분기) — 결정 대기 표로 차단하고 병렬 진행. 프로그램 검토식 결함 발견 시 수정 커밋 분리 + 기존 일람표 회귀 diff 리포트 첨부.
