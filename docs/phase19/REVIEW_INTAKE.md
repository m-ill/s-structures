각 건은 다음 자료를 `verification/evidence/phase19/review/<ID>/`에 준비한다. 기존 P8 자료가 있다면 새로 만들어 대체하지 않고 해당 원본과 hash를 연결한다. 외부 자료의 공개 권한이 없으면 원문 대신 재현 가능한 입력·출처·공개 허용 결과표와 비공개 검토 기록 ID를 기록한다.

- 모델/케이스 JSON: 단위, 경계조건, 질량, 하중·지진파, 힌지/재료/단면과 출처.
- 사전 비교 manifest: 관측량·부호·위치·시간축, 절대/상대 허용오차·분모 하한. 실행 전에 확정한다.
- reference 입력/출력과 실행 프로그램·버전. S-Structures 결과를 reference 값으로 다시 사용하지 않는다.
- S-Structures source commit/runtime hash, 설정, 원본 결과 JSON, 수렴·평형·에너지·실패 로그.
- 비교표: 전체 경로와 주요 극값·잔류값. 불일치나 미수렴을 누락하지 않는다.
- review.md: 검토자, 실제 검토일, 발견사항, 재실행 여부, 적용 범위, PASS/FAIL/BLOCKED 근거. 미검토 상태에서 서명란을 채우지 않는다.

검토가 접수되면 해당 source/build/input 범위만 판정하고, 모델 또는 엔진이 변경된 결과에 이전 승인을 자동 재사용하지 않는다.
