# 02 Modeling And Elastic Analysis

## Modeling Paths

현재 모델은 네 가지 경로로 만들 수 있다.

| 경로 | 사용자 | 용도 |
| --- | --- | --- |
| 화면 모델링 | 일반 사용자 | 직접 절점/부재/하중 작성 |
| native modeler action | AI agent 또는 자동화 | 화면 모델러와 같은 모델을 안정적으로 조작 |
| JSON import | 고급 사용자, 변환기 | 외부 입력 또는 생성 모델 주입 |
| 대표 건물 generator | 검증/테스트 | 10종 대표 형상 자동 생성과 보고서 검증 |

중요한 원칙은 하나다. 새 모델링 표면을 따로 만드는 것이 아니라 기존 `index.html` 모델 객체를 기준으로 엔진, 결과, 보고서가 연결되어야 한다.

## Core Model Entities

| entity | 필수 개념 |
| --- | --- |
| `nodes` | `id`, `x`, `y`, `z`, `support`, 선택적으로 `mass` |
| `members` | `id`, `n1`, `n2`, `matId`, `secId`, `design.role` |
| `materials` | 탄성계수, 전단계수, 밀도 등 |
| `sections` | 면적, 단면2차모멘트, 단면계수 등 |
| `loadCases` | `D`, `L`, `WX`, `WY`, `EX`, `EY` 등 |
| `loads` | `udl`, `point`, `nodal`, `nmoment` |
| `loadCombinations` | 조합 ID, 조합 타입, case별 factor |
| `analysisSettings` | 선형해석, P-Delta, modal/RSA 관련 설정 |

## Screen Modeling Checklist

1. 하부 절점에 `fixed`, `pin`, `roller`, 또는 custom 지점을 둔다.
2. 기둥과 보가 실제 연결되도록 절점 좌표를 맞춘다.
3. 부재에는 적절한 단면과 재료를 배정한다.
4. 보/기둥/브레이스 역할을 지정하면 설계 검토와 하중 산정 trace가 더 읽기 쉬워진다.
5. 층별 모델은 z좌표를 일관되게 사용한다.
6. 하중 방향은 전역 좌표와 부호를 확인한다.
7. 조합을 만들고 해석 결과가 `ok`인지 확인한다.

## Material And Section Palette

모델링 도구의 재료 선택기는 신규 부재 기본값으로 현행 `SS275`를 사용하며 `SM355A/B/C`를 두께 구간별로 제공한다. `SS400`, `SM490`은 기존 프로젝트 보존용 `구규격` 항목이며 기존 부재를 자동 치환하지 않는다.

단면 선택기에는 다음 기본 형상이 포함된다.

| 그룹 | 기본 제공 범위 |
| --- | --- |
| H형강 | H-100급부터 H-600급까지 일반/광폭 모델링 seed |
| 각형강관 | BOX-100부터 BOX-400까지 |
| 원형강관 | PIPE-101.6부터 PIPE-267.4까지 |
| RC 정사각형 | 300x300부터 700x700까지 |
| RC 직사각형 | 300x500, 300x600, 400x600, 400x700, 500x800 |

`＋ 단면 만들기`에서는 `SQUARE`, `RECT`, `CIRC`, `H`, `BOX`, `PIPE` 형상과 mm 치수를 입력한다. 화면은 `A`, `Iy`, `Iz`, `J`를 즉시 계산하고 단면 미리보기를 표시한다. 형상으로 표현하기 어려운 단면은 `GENERAL`에서 `A(cm²)`, `Iy/Iz/J(cm⁴)`를 직접 입력한다.

저장된 단면은 `[프로젝트]`로 표시되고 현재 그리기 기본값이 된다. 기존 부재를 변경할 때는 부재를 선택한 다음 `✓ 선택 부재 적용`을 누른다. 기본 단면은 형상 입력 편의를 위한 seed이므로 최종 설계 전에 프로젝트 단면표와 제조사·KS 치수를 확인한다.

## Elastic Analysis Pipeline

현재 탄성해석은 아래 흐름으로 동작한다.

```text
model validation
-> 3D frame stiffness assembly
-> load case and combination solve
-> reaction/equilibrium check
-> member force recovery
-> envelope and design demand
-> result visuals
-> report data
```

해석 결과에서 우선 확인할 항목은 다음과 같다.

| 결과 | 확인 내용 |
| --- | --- |
| `analysis.ok` | 전체 해석 성공 여부 |
| validation errors | 모델 입력 오류 |
| equilibrium residual | 총하중과 총반력의 평형 오차 |
| max displacement | 최대 변위 |
| member force envelope | 부재별 축력, 전단, 휨 포락 |
| reactions | 지점 반력 |
| design utilization | 예비 설계 검토비 |
| serviceability drift | 층간변위 및 제한비 |

## Result UI

`탄성해석` 탭으로 처음 이동하면 현재 모델에서 완료되지 않은 단계가 자동으로 열린다. 번호 버튼을 따라 기본설정부터 결과검토까지 진행한다.

| 단계 | 하는 일 | 필요한 이유 |
| --- | --- | --- |
| 1 기본설정 | 프로젝트 ID, 설계법, 용도, 지역, 지반, 중요도 입력 | 적용 하중과 조합법의 범위 고정 |
| 2 하중·질량 | D/L/Lr/W/E와 층 질량 적용 | 정적 조합과 동적 질량 입력 통일 |
| 3 하중조합 | KDS 조합 미리보기, 계수·방향 검토, 프로젝트 승인 | 강도와 사용성 조합 혼용 방지 |
| 4 모델검증 | 지점·연결·단면·참조 오류 검사 | 잘못된 입력을 해석 전에 차단 |
| 5 1차해석 | 선형 정적해석과 평형 확인 | 고급해석의 비교 기준 생성 |
| 6 고급해석 | Direct P-Delta, 모달/RSA, 좌굴, 선형 THA 선택 | 검토 목적에 맞는 해석만 수행 |
| 7 결과검토 | 수렴·평형·질량참여·지배조합·경고 확인 | 설계전달 가능 결과 선별 |

상세 하중 입력줄은 기본적으로 접혀 있다. 절차 리본 끝의 `⋯` 버튼으로 표시할 수 있다.

### 하중조합 판정

- `1.0D + 1.0L`은 사용성·처짐 검토 조합으로 사용할 수 있다.
- 같은 식을 `강도` 조합으로 지정한 기존 `CO1`은 새 모델 기본값에서 제거했다.
- 새 D/L 모델은 `KDS22-ST-01 = 1.4D`, `KDS22-ST-02 = 1.2D + 1.6L`, `SLS1 = D+L`로 시작한다. 두 강도조합은 프로젝트 승인 전까지 후보 상태다.
- 기존 저장 모델의 정확한 레거시 `CO1(D+L)`은 로딩 또는 탄성해석 UI 초기화 시 위 KDS 후보로 자동 교체한다. 사용자 수정 조합과 `L`을 활하중이 아닌 다른 하중으로 정의한 모델은 자동 변경하지 않는다.
- 공식 URL과 개정 이력은 연결되어 있지만 원문 파일 hash 독립검증 전이므로, 자동 적용이 아니라 검토자 ID·메모·확인을 포함한 프로젝트 승인 후 적용한다.
- 승인 적용 시 KDS 후보는 프로젝트 승인 조합으로 갱신하고 `SLS1 = D+L`은 `service/deflection` 목적으로 보존한다.

기본 해석은 리본의 `전체 탄성해석`을 한 번 누르면 된다. 프로그램이 1차 정적, Direct P-Delta, 모달, RSA, 탄성좌굴, 선형 THA 전용 케이스를 중복 없이 생성·재사용하고 차례로 실행한다. 기존 Pushover와 비선형 시간이력 케이스는 이 실행에 포함하지 않는다.

| 리본 그룹 | 역할 |
| --- | --- |
| 해석 절차 | 1~7단계 설정, 진행 상태, 단계별 목적 안내 |
| 해석 | 전체 탄성해석 실행, 세부 설정 열기, 완료·검토·실패 요약 |
| 조합 | 표시할 하중조합 선택 |
| 결과 | 1차, P-Delta, 모달, RSA, 좌굴, THA 결과 팝업 바로가기와 캔버스 표시 토글 |
| 보고 | 하중조합, 설계요약, 검증, 계산서 |
| 상태 | 현재 해석 상태와 경고 표시 |

`전체 탄성해석`이 끝나면 Analysis Center가 닫히고 모델링 화면 오른쪽에 1차 결과 팝업이 열린다. 리본의 `1차`, `P-Delta`, `모달`, `RSA`, `좌굴`, `THA` 버튼을 누르면 계산을 다시 하지 않고 해당 결과로 바로 전환한다. 결과가 없는 버튼은 비활성화된다. 모델을 변경하면 상태가 `재실행 필요`로 바뀐다. 톱니 아이콘은 Analysis Center를 열며 조합·질량원·모드 수·스펙트럼·preload·시간이력 기록을 편집하거나 한 케이스만 다시 실행할 때 사용한다.

Analysis Center의 계산 대상은 `Auto`, `CPU precise`, `GPU accelerated`로 구분된다. 현재 릴리스에서 `Auto`와 `CPU precise`는 검증된 CPU f64 경로를 사용한다. `GPU accelerated`는 구현 후보가 있어도 외부 하드웨어·브라우저 및 성능 자격이 완료되지 않아 비활성화되며, 패널에 사유와 CPU 대체 경로가 표시된다. GPU 요청을 CPU로 조용히 바꾸지 않는다.

결과 팝업은 헤더를 끌어 이동하고 우하단 손잡이로 크기를 조절할 수 있다. 기본 높이는 내용에 맞고 화면을 넘으면 본문만 스크롤된다. 폭이 좁은 화면에서는 우측 도킹 대신 화면 안쪽 8px에 고정된다.

| 해석 | 결과 팝업 탭 |
| --- | --- |
| 1차 정적 | 변형, 부재력, 반력, 검정 |
| P-Delta | 전체 횡변위, 층 drift, 부재 chord drift/축력, 수렴 |
| 모달 | 모드형상, 질량참여율, 주기 |
| RSA | 계산응답, 입력스펙트럼, 모드기여, 응답형상 |
| 탄성좌굴 | 좌굴형상, 고유값, 선행축력 |
| 선형 THA | 변위, 속도, 가속도, 입력기록 |

정적 부재력 탭에서 N/V/T/M 성분을 바꾸면 모델 캔버스도 같은 성분만 표시해 여러 선도가 겹치지 않게 한다. P-Delta 결과 상태에서 부재를 선택하면 팝업이 `부재` 탭으로 이동한다. 전체 P-Delta 곡선은 1차와 2차 모두 전역 횡절점변위를 사용하며 횡응답이 없는 조합은 0선으로 표시한다.

| 해석 | Analysis Center에서 확인할 입력 |
| --- | --- |
| 1차 정적 / Direct P-Delta | 하중조합, 2차효과 방식 |
| 모달 | 모드 수, 질량원 |
| RSA | 모드 수, 질량원, SRSS/CQC, 방향, 감쇠비, 가속도 배율, `T:Sa` 점 |
| 탄성좌굴 | 선행 하중조합, 좌굴 모드 수, 반복 한계 |
| 선형 THA | 모드 수, 질량원, 방향, 감쇠비, dt, 기록 단위·배율·가속도 수치열 |

## Advanced Elastic Checks

비선형 정식 엔진 전까지의 고급 탄성 검토는 다음 수준으로 보는 것이 맞다.

| 기능 | 현재 해석 의미 |
| --- | --- |
| P-Delta | `Direct P-Delta`는 접선강성 기반 설계 검토 경로다. 등가 횡하중 반복(`legacy`)은 비교용으로만 남고 설계 전달이 차단된다. 결과는 global/story/member와 조합별로 구분한다. |
| Modal/RSA | lumped mass 기반 모드/RSA. 모드 정규화, SRSS/CQC, 밑면전단력, 층·부재 응답을 제공하며 질량참여 부족은 검토 상태로 표시한다. |
| Elastic buckling | 선택한 정적 preload 조합의 축력으로 탄성 고유치 좌굴계수와 모드를 계산한다. |
| Linear THA | 모드중첩 Newmark 예비 기능이다. 설계 전달은 차단된다. |
| Serviceability drift | 탄성해석 결과에서 층간변위 표 작성 |
| Member design trace | 부재별 검토식과 지배 조합 추적 |

## Common Failure Cases

| 증상 | 점검 |
| --- | --- |
| 해석 실패 | 지점 부족, zero-length 부재, 누락 재료/단면 |
| 변위가 비정상적으로 큼 | 기구, 약한 단면, 하중 단위 오류 |
| 하중이 적용되지 않음 | 하중케이스 ID와 조합 factor 확인 |
| 보고서가 비어 있음 | 먼저 해석이 성공했는지 확인 |
| 층간변위 행이 적음 | z층 좌표와 수직으로 매칭되는 절점쌍 확인 |
