# 08 Collaboration

## Accounts And Projects

The platform supports registration, login, project membership, project roles,
revision history, approval state, file records, imports, evidence records, and
audit logs.

## Revision Workflow

1. Open a project modeler route.
2. Save a revision from the modeler host.
3. Open revisions to compare saved states.
4. Record approval only after the target revision is reviewed.

## Evidence Workflow

Use project evidence APIs for validation records, owner sign-off records, and
final approval aliases. Accepted evidence alone does not mean production
approval; agents must read final approval review state.
