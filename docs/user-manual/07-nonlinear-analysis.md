# 07 Nonlinear Analysis

## Current Scope

Nonlinear features are preliminary. The app exposes pushover traces, hinge
state summaries, nonlinear geometry traces, PMM hinge interpolation, fiber
moment-curvature helpers, and NLTH trace contracts.

## Workflow

1. Build and validate an elastic model first.
2. Assign material and section records with nonlinear metadata where available.
3. Run pushover for preliminary capacity checks.
4. Read convergence, hinge, and control logs before interpreting results.
5. Export the nonlinear trace for reviewer sign-off.

## Limits

Current nonlinear output is a review artifact, not a certified final nonlinear
design result. Production use requires the validation WPs and owner approval.
