# 01 Getting Started

## Open The App

개발 서버를 실행한 뒤 브라우저에서 아래 주소로 접근한다.

```text
http://127.0.0.1:5173/index.html
```

루트 주소(`/`)와 `index.html`이 다르게 보이면 오래된 서버 또는 캐시가 남아 있을 수 있다. 현재 기준의 작업 화면은 `index.html` 진입을 기준으로 검증한다.

## Main Work Tabs

상단에는 네 개의 큰 작업 탭이 있다.

| 탭 | 목적 | 현재 사용 기준 |
| --- | --- | --- |
| 모델링 | 구조 모델 생성/편집 | 기본 시작 위치 |
| 탄성해석 | 조합, 결과, 설계기준 입력, 보고서 | 해석과 보고서 작업의 중심 |
| 비선형해석 | pushover 예비 기능 | 연구/검토용, 정식 설계 결과로 취급하지 않음 |
| 태블릿메모 | 펜, 지우개, 이미지, 선택 | 현장 메모 또는 검토 표시 |

태블릿 사용을 고려해 왼쪽 모델링 도구는 접었다 펼 수 있게 두고, 상단 리본은 작업 모드별 핵심 기능만 노출하는 방향이다.

## Basic User Flow

1. `모델링` 탭에서 구조 골조를 만든다.
2. 절점, 부재, 지점조건, 단면, 재료를 확인한다.
3. 부재 하중 또는 노드 하중을 입력한다.
4. `탄성해석` 탭에서 하중조합과 결과 표시를 확인한다.
5. 필요하면 설계기준 입력값을 preview 후 apply 하여 자동 하중을 생성한다.
6. 해석 결과에서 변위, 부재력, 반력, 포락, 층간변위를 검토한다.
7. `설계요약`, `검증`, `Calculation Package` 메뉴로 보고서를 연다.
8. 브라우저 인쇄 기능으로 PDF를 저장한다.
9. 프로젝트 JSON 또는 product book 형태로 저장한다.

## Minimum Valid Model

해석 가능한 최소 모델은 다음 조건을 만족해야 한다.

| 항목 | 조건 |
| --- | --- |
| 절점 | 고유 ID와 3D 좌표가 있어야 함 |
| 부재 | 서로 다른 두 절점을 연결해야 함 |
| 재료/단면 | 부재가 참조하는 재료와 단면이 존재해야 함 |
| 지점 | 전체 모델이 강체 운동을 하지 않도록 충분한 구속이 있어야 함 |
| 하중 | 하중케이스에 연결된 부재하중 또는 노드하중이 있어야 함 |
| 조합 | 하중케이스를 참조하는 하나 이상의 조합이 있어야 함 |

## Save And Restore

현재 프로그램은 JSON 모델과 native persistence 흐름을 기준으로 한다.

| 기능 | 설명 |
| --- | --- |
| 예제 열기 | 내장 예제 모델을 현재 화면에 로드 |
| 저장 | 현재 모델과 설정을 내보냄 |
| 불러오기 | 저장된 모델을 다시 현재 화면으로 로드 |
| autosave | 브라우저 저장소에 현재 작업 상태를 저장/복원 |

저장 파일은 나중에 도면, 이미지, MGT, AI vision import 결과가 들어올 때의 공통 중간 형식으로도 쓰인다.
