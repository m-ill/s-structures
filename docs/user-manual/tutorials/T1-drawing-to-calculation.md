# Tutorial T1 - Drawing To Calculation

Goal: import a drawing candidate, review the overlay, save a revision, and open
a calculation package.

1. Create a project.
2. Upload the sample DXF from `samples/onboarding/office-frame-sample.json`.
3. Open the import review route.
4. Select one overlay member and confirm the candidate.
5. Save the generated model as a revision.
6. Run elastic analysis.
7. Open the calculation package.

Expected result: one project revision and an HTML calculation package.
