## 1. 문제와 목표

정적, Direct P-Delta, 모달, RSA, 탄성좌굴, 선형 THA 엔진은 코드에 연결되어 있었지만 탄성해석 리본에는 P-Delta 결과 토글과 배율만 노출됐다. 사용자는 엔진의 존재를 알기 어렵고 Analysis Center의 raw kind 목록으로 들어가도 고급 탄성 설정을 편집할 수 없었다.

UI 목표는 다음과 같다.

1. `전체 탄성해석` 한 번으로 여섯 탄성 케이스를 생성·재사용하고 연속 실행한다.
2. 해석 종류 버튼은 설정창이 아니라 해당 결과 팝업을 바로 연다.
3. 기본값으로 바로 실행하되 필요할 때만 Analysis Center에서 개별 입력을 수정·재실행한다.
4. 미실행, 실행 중, 완료, 실패, 재실행 필요, 검토 필요, 예비 상태를 리본과 패널에서 같이 표시한다.
5. 해석 실행과 결과 표시를 분리한다. 결과 바로가기는 계산 설정을 바꾸지 않고 저장된 결과만 연다.
6. 기본설정부터 결과검토까지 번호 순서로 진행하며 각 단계가 필요한 구조공학적 이유를 표시한다.
7. 잘못된 legacy 강도조합을 탐지하고 KDS 규칙 미리보기와 프로젝트 승인 절차로 교체한다.

## 2. 7단계 설정 흐름

`기본설정 -> 하중·질량 -> 하중조합 -> 모델검증 -> 1차해석 -> 고급해석 -> 결과검토` 순서다. 미완료 단계에는 `!`, 완료 단계에는 `✓`를 표시한다. 탄성해석 탭 첫 진입 시 프로젝트 ID·설계법 누락, 미승인 KDS 후보 또는 승인 강도조합 부재가 있으면 첫 필요 단계를 자동으로 연다.

하중조합 단계는 다음 계약을 따른다.

- 신규 모델에는 `strength: 1.0D+1.0L`을 생성하지 않는다.
- 정확한 legacy 기본 `CO1(D+L)`은 초기화 시 `KDS22-ST-01/02` 후보로 교체한다.
- `service: 1.0D+1.0L`은 사용성 baseline으로 유지할 수 있다.
- KDS 41 12 00:2022 source-attached rule pack으로 설계법별 조합을 미리보기한다.
- source hash 독립검증 전에는 전역 자동승인을 허용하지 않는다.
- 프로젝트 ID, 검토자, 검토시각, 메모, factor snapshot hash를 고정한 프로젝트 승인 후 적용한다.
- 사용자 수정 조합과 D/L 의미가 다른 사용자 모델은 자동 교체하지 않는다.

## 3. 리본 정보구조

| 명령 | 생성 케이스 | 주요 설정 | 결과 상태 |
| --- | --- | --- | --- |
| 1차 정적 | `static`, `pDeltaMethod=off` | 하중조합 또는 전체 조합 | 설계 전달 gate 적용 |
| Direct P-Delta | `static`, `pDeltaMethod=direct` | 하중조합, Direct 방식 | 수렴·지원범위 충족 시 전달 가능 |
| 모달 | `modal` | 모드 수, 질량원 | 주기·모드·질량참여율 |
| RSA | `responseSpectrum` | 모드 수, 질량원, SRSS/CQC, 방향, 감쇠, 스펙트럼 | 방향별 응답과 조합 결과 |
| 탄성좌굴 | `buckling` | 선행 하중조합, 모드 수, 반복 한계 | `lambda_cr`와 좌굴 모드 |
| 선형 THA | `linearTha` | 모드 수, 질량원, 방향, 감쇠, dt, 기록 단위·배율·가속도 | `preliminary`, 설계 전달 차단 |

리본의 기본 명령은 `전체 탄성해석`이다. 이 명령은 표의 여섯 케이스만 생성·재사용해 순차 실행하고 Pushover/NLTH 등 비선형 케이스는 실행하지 않는다. 결과 그룹의 `1차/P-Delta/모달/RSA/좌굴/THA` 버튼은 계산을 다시 시작하지 않고 해당 결과 팝업을 바로 연다. 미실행 결과 버튼은 비활성화하며 완료·검토·실패·재실행 필요 상태를 버튼에 표시한다. 톱니 아이콘은 선택 입력을 세부 조정하는 Analysis Center를 연다. 사용자가 수정한 케이스 설정은 전체 재실행에서도 보존한다.

## 4. Analysis Center 입력 계약

| 해석 | 필수 UI 입력 |
| --- | --- |
| 정적/P-Delta | 조합, `off/direct/legacy` 방식 |
| 모달 | 모드 수, 프로젝트 질량원 또는 노드·부재 질량 |
| RSA | 모달 입력 + SRSS/CQC + X/Y/Z + 감쇠비 + 가속도 배율 + `T:Sa` 점 |
| 좌굴 | 검증된 선행 정적 조합 + 좌굴 모드 수 + 최대 반복 |
| 선형 THA | 모달 입력 + 방향 + 감쇠비 + dt + 가속도 단위/배율 + 기록 ID/수치열 |

컨트롤 변경은 선택 케이스에 자동 저장되고 `설정 저장`으로도 명시적으로 확정할 수 있다. 실행 시 화면 값을 다시 읽어 저장한 뒤 solver runner를 호출한다.

## 5. 우측 통합 결과 팝업

해석 설정은 Analysis Center, 실행 결과 검토는 `canvasWrap` 우측의 `탄성해석 결과` 팝업이 담당한다. `전체 탄성해석`이 끝나면 Analysis Center를 닫고 1차 결과 팝업을 자동으로 연다. 이후 결과 그룹의 여섯 버튼으로 같은 팝업 내용을 즉시 전환한다. 기존 하단 `P-Delta 결과` 중복 버튼은 제거하고 변형 배율만 별도 표시 제어로 유지한다.

| 결과군 | 전용 시각화 |
| --- | --- |
| 1차 정적 | 변형 형상, 선택 부재 station N/V/T/M 선도, 부재별 최대값, 지점 반력, 검정비 |
| Direct/legacy P-Delta | 조합별 하중계수-전역 횡변위, 층별 1차/2차 drift, 선택 부재 chord drift·축력, 반복 수렴 norm |
| 모달 | 모드형상, X/Y/Z 모드별·누적 질량참여율, 고유주기 |
| RSA | 입력 스펙트럼, 방향별 계산 변위·밑면전단력, 모드별 변위·밑면전단력, 조합 응답형상 |
| 탄성좌굴 | 모드별 좌굴형상, `lambda_cr`, residual, 선행 압축력 |
| 선형 THA | 변위·속도·상대가속도·입력 지반가속도 시간이력과 스텝 값 |

Direct P-Delta의 전체 곡선은 1차와 2차 모두 **전역 횡절점변위 resultant**를 사용한다. 부재 처짐 최대값과 절점 횡변위를 한 축에서 비교하지 않는다. 선택 조합의 횡응답이 0이면 가상의 곡선을 만들지 않고 0선과 횡하중 조합 선택 안내를 표시한다.

팝업은 다음 배치 계약을 따른다.

- 기본 위치는 모델 캔버스 우측 12px, 내용량에 따라 폭 360/440/520px과 자동 높이를 사용한다.
- 캔버스를 넘으면 본문만 스크롤하고 헤더·닫기·탭은 유지한다.
- 헤더 드래그, 우하단 크기조절, 18px 경계 스냅, 위치 저장을 지원한다.
- 사용자가 직접 크기를 바꾸기 전에는 탭 내용에 따라 자동 크기를 다시 계산한다. 직접 바꾼 크기는 저장하고 resize handle 더블클릭으로 초기화한다.
- 폭 720px 이하에서는 캔버스가 지나치게 작아질 수 있으므로 화면 inset 8px의 고정 팝업으로 전환한다. 이 전환에서는 데스크톱 위치를 다시 저장하지 않아 우측 기본 배치와 사용자가 이동한 위치를 보존한다.
- 결과 선택 저장소의 케이스, 모드/스텝, 방향, 성분, 선택 부재를 구독한다. P-Delta 결과에서 부재를 선택하면 중복 소형 패널을 만들지 않고 `부재` 탭으로 이동한다.

## 6. 상태와 제한

- 모델 변경 후 기존 성공·실패·예비 결과는 `stale`이 되며 리본에 `갱신`으로 표시한다.
- legacy 등가하중 반복 P-Delta는 비교용이며 설계 전달이 차단된다.
- 선형 THA는 모드중첩 Newmark 계산 경로가 있으나 구조 전체 응답의 독립 실증이 완료되지 않아 예비 상태를 유지한다.
- 좌굴은 3D 프레임과 자격을 갖춘 정적 preload 범위다.
- RSA 기본 스펙트럼은 입력 폼을 열기 위한 seed일 뿐 프로젝트 기준 스펙트럼을 대신하지 않는다.
