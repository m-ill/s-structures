## 문맥

리뷰 지적: 12DOF 프레임 요소는 GJ(St.Venant)만 있어 개방단면 warping·정밀 횡비틀림좌굴(LTB)을 표현할 수 없다.
Cw는 단면 스냅샷에 이미 저장되어 있으나 소비자가 없다.

## 선택지

**옵션 A — 7DOF Vlasov 요소 (해석적 해법)**
- 절점당 7DOF(뒤틀림 θ'), 부재 14×14. GJ+EC_w 결합 강성, 뒤틀림 경계조건.
- 장점: warping 응력·비틀림좌굴까지 해석적으로 정확.
- 비용/리스크: **전 시스템 파급** — canonical domain DOF 규약(절점 6DOF)이 P8-M1 이후 탄성·비선형·compute(P9 domainBinary·GPU 커널)에 공유됨.
  7번째 DOF는 descriptor·hash·sparse 패턴·워커 프로토콜 전부에 영향. 공수 대(별도 페이즈급).

**옵션 B — 설계식 LTB 검토 (check 계층)** ← **권고**
- 해석 DOF 불변. M_cr 폐형식(§8) + C1 모멘트구배 + 횡지지 길이로 부재별 검토값 산출.
- 장점: 실무 수요(강재 보 LTB 검토)를 즉시 충족, 기존 해석·compute 자산 무영향, 상용 프로그램도 보편적으로 채택하는 접근.
- 한계: warping 응력 자체는 미제공 — limitations 명시.

## 권고안

**옵션 B를 P10-M8로 구현하고, 옵션 A는 수요 확인 시 후속 페이즈로 이연한다.**
근거: 파급/가치 비 — 검토 계층은 리뷰 지적("지원하지 않는 항목은 명확히 밝혀야")을 충족하면서 6DOF 계약을 보존한다.
