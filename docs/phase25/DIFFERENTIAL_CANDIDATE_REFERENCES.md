# 기초 후보와 부등침하 참조 버전

## 문제와 동작

기초 F2를 수정해 새 버전으로 만들면 F1의 명시 비교참조 F2@1이 오래된 입력이 되어, 변경 후 부등침하 검토를 수행하지 못했다. 자동 후보 생성 시 현재 기준선의 peer 참조를 새 후보 버전에 연결하는 명령을 같은 거래에 포함한다. 일반 수동 변경은 기존처럼 오래된 참조를 미검토로 표시한다.

`rebindDifferentialPeerCommands`는 최신 기초 레코드에서 역참조를 한 번 만들고 변경대상부터 연결을 순회한다. 참조가 바뀌는 기초도 새 버전을 만들기 때문에 해당 기초를 참조하는 상위 기초까지 연결한다. 순환 연결은 방문집합으로 종료하며 각 기초는 한 번만 버전을 올린다. 후보가 이미 수정하는 기초의 형상·입력은 유지하고 peer 참조만 교체한다.

기준선의 최신 버전과 정확히 일치했던 참조만 갱신한다. 이미 오래된 참조를 임의로 최신값으로 인증하지 않는다. 잠긴 의존 기초, 중복 명령, 버전 또는100명령 한도 위반은 후보 거부로 처리한다. 원본 모델과 명령을 수정하지 않고 새로운 명령배열을 반환한다. 허용침하·허용각변위·판정근거를 낮추거나 바꾸지 않는다.

## 실행과 조회

원본 후보와 관련 상세 명령을 생성한 뒤, 해시/중복제거/스테이징 이전에 참조 명령을 확장한다. 이후 기존 격리 평가 Worker와 재해석 판단·전체 후보 영향범위·실제 적용후 재검토를 통과한다. 자동 참조변경 기초도 명령으로 포함되어 영향범위에서 제외되지 않는다. 참조만 바뀐 기초를 추가 물량으로 합산하지 않는다.

후보 요약의 differentialReferences는 기초ID/버전/갱신참조수/추가명령 여부를 표시한다. 상세 JSON의 foundationChanges는 기준선과 후보 입력 및 changedFields를 제공한다. 기존4096자 청크조회와 예산관리 텍스트 캐시/스트리밍 경로를 공유한다. 원본 레코드를 캐시에 추가 보관하지 않는다. 실제 적용은 하나의 입력거래이며 undo로 함께 복원한다.

## 명시 허용치수와 후보 제한

foundation-record의 `footprintLimitB`, `footprintLimitL`, `footprintLimitReference`로 현재 위치/방향에서 허용하는 기초 B/L 치수를 입력한다(eval135/strategy114/footprint-proposal-v2). 두 치수·근거 일부가 없으면 입력 보완 대상이다. 기존 기초가 제한을 넘는 상태도 기록/검토할 수 있으며 `foundation-footprint-fit` NG로 표시한다. 선언이 있는 기초에서 해당 검사를 생성하여 전체 기초집계에도 포함한다.

자동 후보는 선언한 치수 제한, 기존1.5배 탐색범위와100m 한도를 함께 지킨다. 한 축이 제한에 도달하면 다른 축의 여유를 써서 목표면적에 접근한다. 두 축 모두 여유가 없거나 현재 치수가 이미 제한을 넘으면 확대 후보를 생성하지 않는다. 수치 반올림으로 hard limit을 넘기지 않도록 마지막 상한 비교를 유지한다. 기존의 비례 확대는 축 제한이 없는 경우의 기본 추정이며 제한된 경우에는 비대칭 확대가 가능하다. 모든 후보는 배근·접촉·침하·부등침하 재검토 대상이다.
