# 기초 저면 수평력·비틀림 마찰 진단

상태: 역학적 범위 진단 구현, KDS 설계저항 자격 미완료 · 2026-09-12

## 근거와 적용 범위

- KCSC 공식 저장 원문 `verification/evidence/phase25/kcsc/official-20260911/KDS-115005-official.json`: KDS 11 50 05(2025) 1.9(5), 4.1.7(1). 활동 안정과 허용수평지지력의 안전율 적용을 검토해야 한다. 공식 출처: https://kcsc.re.kr/OpenApi/CodeViewer/KDS/115005
- FHWA GEC No. 6 §5.4는 저면 마찰과 수동저항의 역할을 설명한다. https://www.fhwa.dot.gov/engineering/geotech/pubs/010943.pdf
- 아래 상·하한 구성은 주어진 압력과 Coulomb 마찰 가정으로 유도한 프로그램의 역학 진단이다. KDS가 규정한 비틀림 상호작용식으로 인용하지 않는다. 안전율·점착력·수동저항·연약층의 별도 활동면·지반변형은 포함하지 않는다.

## 계산 구성

압축 접촉 다각형에서 주어진 선형 압력 q를 적분하여 N, 압력 중심 c를 구한다. 입력 축력과의 평형 및 비음수 압력·볼록 영역을 확인한다.

균등 비율 전단장 q H/N의 합력은 H이고, 압력 중심에 따른 모멘트는 c_x H_y - c_y H_x다. 별도로 저항할 비틀림은 T_c = T - (c_x H_y - c_y H_x)다.

각 축에서 압력 중심을 지나는 선으로 접촉 영역을 나누고, 두 영역의 수직력 N+와 N-, 압력 중심 사이 거리 d를 적분한다. 양측 전단력을 μ min(N+,N-)로 같게 만들면 순수 모멘트 저항 μ min(N+,N-) d를 구성할 수 있다. 두 축 중 큰 값을 C_lower로 선택한다. 각 영역의 마찰 사용 비율은 min(N+,N-)/N_side 이하이며 두 힘의 합력은 0이다.

삼각부등식에 의해 |H|/(μN) + |T_c|/C_lower ≤ 1이면 이 가정 내에서 허용 전단장을 구성할 수 있다. 이를 충분조건으로만 사용한다. 이를 초과한 경우만으로 NG를 내리지 않는다.

한편 반드시 |H| ≤ μN 및 |T_c| ≤ μN r_max를 만족해야 한다. 여기서 r_max는 압력 중심에서 접촉 다각형까지 거리의 상한이다. 이 필요조건을 초과할 때는 주어진 마찰 가정 내 NG로 기록한다. 충분조건도 만족하지 않고 필요조건도 위반하지 않는 중간 영역은 UNRESOLVED다.

## 결과 연결과 제한

`foundation-sliding.baseFriction`에 CALCULATED, FEASIBLE_BOUND/UNRESOLVED/NG, 상·하한 저항, 압력 중심, 순수 비틀림 수요와 평형을 이루는 전단력 쌍을 기록한다. 유한한 직선 마찰 한계 또는 모멘트 저항 상한 초과는 NG로 유지하지만 KDS 방법 검토의 incomplete도 함께 보존한다. 충분조건 통과만으로 foundation-sliding을 KDS OK로 올리지 않는다. 기본 전체 판정은 NOT_CHECKED이며 capacityQualified=false다.

배열은 최대16개 접촉 꼭짓점과 두 축의 적분만 사용한다. 반복적인 접촉면 메시나 최적화 배열을 만들지 않는다.

## 집중 검증

균등 정사각형의 순수 비틀림 하한 25 kN·m, 수평력 50 kN, 보수적 중간영역, 저항 상한 초과, 압력 중심 이동에 대한 불변성, 삼각형 접촉의 힘 평형, 길이 배율, 잘못된 접촉 영역을 검증했다. 실제 WebMCP 절점 비틀림 입력→해석→기초 검토→상세조회와 큰 비틀림 NG/미완료 동시 보존을 확인했다. 외부 해석기 대조 및 최종 방법 자격은 남아 있다.

## 명시적 사용하중 안전율 입력

`ground-record.slidingMethod = "coulomb-service-safety-factor"`, `slidingSafetyFactor`, `slidingFactorReference`를 입력하면 사용하중의 미끄럼 허용저항을 `μN / FS`로 계산한다. 안전율과 근거는 자동 선정하지 않는다. 입력 계약은 FS 1~100을 허용하지만 해당 값이 현장·지반 조건에 적합하다는 검증은 별도이며 `safetyFactorVerified=false`를 유지한다. 기존 미지정 방식은 제공 입력의 역학 결과로 남는다.

이 방식에서는 강도조합을 N_A로 표시하며, 서비스 조합의 검토를 대신하지 않는다. 순수 비틀림 수요가 남으면 안전율을 반영한 마찰 상·하한 진단을 제공하되 방법 미검토를 유지한다. 순수 수평력의 계산에는 공식 KDS 11 50 05(2025) 4.1.7(1) 근거를 연결한다. CLAUSE_APPLIED는 기존 시스템의 출처·조항 연결 판정이며, 선정 안전율이나 전체 지반 설계의 독립 승인이 아니다.

집중 시험에서 안전율 3과 1.2의 명시적 입력 변경에 따른 계산 차이를 비교했다. 이는 식의 검증이며, NG를 해소하기 위해 안전율을 낮추라는 권고 또는 자동 최적화 전략이 아니다. 현장 근거 없이 안전율을 변경하는 후보는 생성하지 않는다.
