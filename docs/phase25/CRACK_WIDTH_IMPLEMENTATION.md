# M3 지속하중 균열폭 계산

2026-09-13 · 현재 evaluator195 · 구현 진행 중, 전체 구조설계 적합성 미확정

현재 요약: 무수축 지속 유효탄성계수 해석의 단면응력→균열폭 연결 구현. 인장철근량 필터 오류 수정 후 실제 휨21개 위치 중20개 계산/1개 미검토. 아래 최초 구현 설명 뒤에 버전별 변경 이력을 보존한다. 현재 식·원문·시험 대응은 CRACK_WIDTH_RULE_MAP.json 참조.

## 근거와 계산

KCSC 공식 캡처 `verification/evidence/phase24/kcsc/KDS-142030-official.json`의 KDS 14 20 30:2021 **부록** 4.1.1~4.1.3, 식 4.1-1~7, 표 4.1-1을 사용한다. 캡처의 MathType `data-script`를 직접 확인했다. 공식 뷰어 재조회는 도구에서 실패하여 저장된 판본에 근거했다. 최신 개정판 전반의 재조사를 의미하지 않는다.

조항 대장 생성기는 원본 SHA-256을 retrieval-manifest와 확인하고 본문·부록의 heading/token을 별도로 기록한다. `documentPart: appendix` 없이 부록 조항을 본문 규칙으로 인정하지 않는다. 결과에는 판본·조항·부록 표시·공식 URL·원본 해시가 붙는다.

`kdsCrackWidth.js`는 mm/MPa 입력으로 유효인장면적, 철근비, 평균 균열간격, 평균 변형률차, 설계 균열폭과 환경별 허용폭을 계산한다. 유효인장강도와 평가계수는 명시 입력이다. 혼합 직경은 면적/직경 합의 비로 환산한다. 단면 응력은 기존 압축 콘크리트/탄성 철근 균열단면 해석기로 평형을 구하고, 해석기와 단면의 축·부호를 공통 변환한다.

독립 산술 사례: H=600, b=300, x=200, d=540, As=800mm², c=40, db=20, 간격150mm, fs=200MPa, Es=200000, Ec=25000, fcte=3, k2=0.5, 평가계수1.7. 유효깊이133.333333mm, 철근비0.02, 평균간격180mm, 변형률차0.000652, 설계폭0.199512mm, 건조환경 허용폭0.4mm. 이 사례는 단면 평형 결과와 별개인 식 검증용 입력이다.

## 입력 및 공통 결과 연결

`crackControlStandard=KDS-142030-2021-appendix`를 명시 선택한다. 추가 입력은 `crackWidthEnvironment`, `crackEffectiveTensileStrength`, `crackTensileStrengthReference`, `crackEvaluationFactor`, `crackSustainedLoadReference`이며 기존 `serviceSustainedComboId`로 지속하중을 지정한다. 일반 특별요구 없음과 온도·수축 추가보강 필요 여부도 명시해야 한다. 자동 기본값으로 채우지 않는다.

동일 typed 계약을 UI와 WebMCP preview/apply가 소비한다. 공통 평가기가 실제 배근·이음 위치에 따른 각 station을 검사하며 결과/보고서가 준비된 수치를 소비한다. 지속조합 외의 행은 해당 조합 결과가 존재할 때만 companion을 가리킨다. 지속조합이 없으면 미검토다. 모든 고정하중의 계수1 및 조합의 유효 케이스를 검사한다.

## 완료된 계산과 남은 범위

종방향 압축·인장 및 단축휨의 검토 경로를 추가했다. 전체 단면 네 모서리가 압축일 때만 종방향 균열폭0을 반환한다. 휨이 있으면 실제 철근응력·중립축·유효인장영역을 사용한다. 축 회전/부호 반전 결과를 비교했다. 비대칭 배근 때문에 발생하는 양축 곡률도 감지한다. 탄성 철근/콘크리트 범위를 초과한 상태를 통과시키지 않는다.

양축휨 유효인장영역, 지속하중의 시간 의존 단면응력, 온도·수축 균열, 특수 수밀/미관 요구, 직교 보강의 주응력 방향 검토는 미완료다. 통합 결과는 `methodReviewRequired=true`를 유지한다. 계산 OK를 전체 KDS 적합으로 승격하지 않는다. 압축부재 처짐/변형과 Direct 국부 안정도 이 변경으로 완료되지 않는다.

## 2026-09-13 M3 장기 해석과 균열폭 응력 기준 혼합 차단

현재 코드를 대조한 결과 sustained-effective-modulus 해석은 지정 유효탄성계수를 사용하지만, 부록 균열폭 owner는 전달받은 부재력에서 원래 단기 Ec로 단면 응력을 다시 계산했다. 장기 변형/응력 경로가 구현되지 않은 상태에서 이 조합을 수치 OK로 내보내는 것은 잘못된 연결이다. evaluator188은 CRACK_WIDTH_TIME_DEPENDENT_SECTION_STRESS_REQUIRED/NOT_CHECKED와 sourceTimeEffect·실제 적용 creep effect를 반환한다. 일반 순간 단면/기존 균열폭 계산을 제거하지 않는다. 이 차단은 장기 균열폭 구현 완료가 아니다.
