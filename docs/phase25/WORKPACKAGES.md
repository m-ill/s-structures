## M1 — KDS 적용성·동시 수요·공통 완료 판정

대상: G02~G06. 진입: M0 프로파일/규칙 대장.

1. `codeBasis` v2에 documentId/edition/hash, 존재하는 clauseId/equationId/tableId, 구현 ruleId/version, 적용 조건 결과, 계산/검토 상태를 연결한다. 계산 대상·수요·입력/규칙 hash도 보존한다. 실제 source hash에 가짜 조항을 붙이는 A05부터 RED로 만든다.
2. `ULS`, 전체 `SLS`, 순간 live, sustained/post-attachment, probable-strength 수요를 구분한다. 프로젝트의 D/L/roof/snow/wind/seismic 등 필요한 load family와 방향/부호/조합을 규칙 대장에서 요구한다. 비적용에는 근거가 필요하고 missing/assumed/manual-confirmed/derived를 구분한다. 전체 사용하중에 D가 빠진 A02를 차단한다.
3. 고정 배열의 단순 행 반복을 applicability matrix로 교체한다. 해당 조합에 적용되지 않는 검사를 N_A로 만들 때 적용 제외 근거를 기록한다. 미구현·입력 누락을 N_A로 바꾸지 않는다. code-compliance는 자신을 재귀적으로 필수검사에 포함하는 placeholder가 아니라 하위 규칙·조합 coverage·입력 확인의 집계다.
4. `evaluateDesign`, finalizer, `elasticReviewService`, practical service의 결과 준비 소유자를 하나로 정한다. legacy 진단은 별도 채널로 남기고 canonical summary/checkId/governing을 UI/보고서가 공유한다. cache key는 모델·정확한 source set·조합·규칙·해석 방법을 포함한다.
5. N/My/Mz/V/T의 조합·station·축·부호·offset/release·해석 차수를 함께 검증한다. station 단조성/중복/범위/배열 완전성을 검사하고 특이점 양쪽 값은 별도 side 키로 보존한다. 기계적으로 중복을 삭제하지 않는다. 기존 Direct 수렴 선택기는 보존한다.
6. gross/균열·장기 강성, 전역 P-Delta/국부 2차 효과를 명시하고 변경 영향표를 갱신한다. 배근 변경이 강성에 쓰이는 모드에서는 기존 배근-only 재사용을 허용하지 않는다. 같은 결과라도 source 자격과 rule version이 달라지면 stale이다.

## M2 — 실제 재료·배근 구간·KDS 상세 규칙

대상: G07/G08/G11. 진입: M1 검사/적용 계약.

1. 기존 네 재료 입력은 보존한다. 철근은 공칭 규격·공칭 면적/질량·실제 직경·등급·연성/도막·제조/시험 출처를 구분한다. 공칭 규격 선택과 임의 기하 직경 입력은 서로 다른 근거다. 기준에 없는 제품을 자동 후보로 만들지 않는다.
2. 부재 역할·내진 상세 구역·피복 환경/노출·골재·층/다리 수·횡구속 위치·사용 구간을 typed 입력으로 연결한다. UI와 WebMCP는 하나의 field/schema/validator를 이용한다. 기존 필드의 단위/의미를 migration 없이 바꾸지 않는다.
3. 배근 구간은 통상 반개구간, 마지막 구간의 끝 포함 등 명시 규칙을 정한다. 실제 이음 겹침은 독립 객체로 표현한다. 인접 경계를 임의 중복 처리하지 않으며 공백/충돌은 별도 이유를 준다.
4. 역할·환경·시스템별 최소/최대 철근량, 순간격, 층 배치, 피복, 띠/스터럽 구속 규칙을 KDS/KS 대장에 연결한다. 현재 mechanicsLaw 검사는 호환 진단으로 남긴다.
5. 배근 객체로부터 d·As·공칭/기하 면적·구속 구역을 결과 준비 단계에서 계산해 강도·정착·도면이 공유한다.

수정 책임: `materials/`, `practicalInputContract`, `practicalDesignInputs`, `designDetailValidation`, 제안 `src/design/detailing/`, 공통 입력/undo/io.

작은 TDD: P25-T02a 공칭/기하 면적 분리와 단위 왕복, T02b A04 경계·공백·이음, T02c 피복/골재/간격 한계 양쪽, T02d 단부/중앙 구속과 1건의 실제 WebMCP preview/apply/undo.

완료: typed 상세가 저장·수치·도면에서 동일하고 프로파일의 상세 검사가 임의 mechanicsLaw 없이 KDS 근거로 판정된다.

## M3 — RC 부재 강도·안정·사용성 완결

대상: G09/G10/G13. 진입: M2 실물 상세, M1 요구 조합/강성 계약.

1. 기존 변형률 적합·축력/양축휨 kernel을 재사용한다. 고강도 중간값/표의 적용·단면/재료 상한, 최소 변형률, 압축 제한과 부호·축 전환을 확인한다. 수렴 실패를 여유율 0으로 바꾸지 않는다.
2. 전역 Direct 해석만으로 국부 기둥 2차/세장·균열/지속하중 요구가 모두 만족했다고 가정하지 않는다. 적용 기준의 경로별 전제와 효과 중복/누락을 검사한다. 실제 해석에 반영한 항과 설계 증폭 항을 trace로 남긴다.
3. 제공 전단철근의 KDS 규칙을 프로파일에 맞게 확장하고 전단-비틀림, 단면 상한/최소철근/정착·내진 수요를 연결한다. 미지원 깊은보/개구부/특수 단면은 원래 확장 범위와 일치하게 사전 차단한다.
4. 현재 순간 live 곡률 적분에 전체 SLS 균열강성의 완전성·지역별 배근/강성·경계조건·지점변위·연속성 경로를 연결한다. 이 기능으로 전체 프레임 균열 강성 재분배를 자동 입증했다고 표현하지 않는다.
5. 지속하중 비율·기간·압축철근·비구조요소 부착 시점/손상 조건을 입력받아 장기/부착 후 처짐을 계산한다. 함수 하나의 계수 계산에 그치지 않고 필요한 SLS 해석→상세→최종 변위까지 연결한다. 균열 제어 규칙도 선택한 프로파일의 실제 조건으로 평가한다.

작은 TDD: P25-T03a 독립 단면 평형/축 회전·압축상한, T03b 2차 효과 포함/중복/누락 1쌍, T03c 전단/비틀림 경계, T03d 즉시/장기·부착 시점·균열 검토 1건씩. 수치 단위/absTol/relTol은 각 규칙의 독립 worksheet에 고정한다.

## M4 — 실제 단부 정착·이음·접합 수요와 구속

대상: G12/G14/G15. 진입: M2 상세, M3 부재 내력/철근력.

1. 철근별 양단 위치·직선/후크/이음·인장/압축/부호 전환·정착 유효 구간을 모델링한다. 기존 길이 함수와 실제 형상 checker를 연결해 도면에만 존재하는 후크를 없앤다. A/B 인장 이음 및 지원할 압축 이음·이음 위치/집중 비율을 규칙별로 구현한다.
2. 구조시스템/내외부/모서리 접합의 실제 적용 규칙을 분기한다. 필요한 경우 보의 예상 강도에서 접합 수요를 자동 산정한다. 축력·지배 방향·기둥/보 단부를 유지하고 임의 수동 `capacityDemandReference` 문자열로 계산 완료를 대체하지 않는다.
3. 패널 전단, 접합 횡구속·철근 연속성/정착·혼잡·시스템별 기둥/보 강도 관계를 각각 검사한다. 배근·단면을 바꾸면 종속 수요/내력/형상 검토를 무효화한다.
4. 평형·구속·offset·강역과 실제 접합 상세가 같은 가정을 갖도록 한다. 지원하지 않는 semi-rigid/특수 편심은 강접으로 덮지 않는다. 기둥-기초 정착을 M5가 동일 객체로 소비하도록 한다.

## M5 — 독립기초의 하중 회계·구조·지반 검토

대상: G16~G19. 진입: M3 RC 규칙, M4 기둥 정착, M1 조합/근거.

1. 반력의 자중 포함 여부·기초 밀도/치수·자중 load case·조합계수, 상재토·지하수/부력의 분포와 위치를 기록한다. 포함된 무게는 다시 더하지 않는다. 서비스/강도 반력의 사용 위치를 분리한다.
2. 접촉압은 외력 합력과 평형을 확인하고, 기초 휨/전단은 절단면 한쪽의 토압과 자중/상재토 등 모든 힘의 순작용으로 적분한다. 들림·부분 접촉에서 역휨을 무시하거나 양의 저면압으로 덮지 않는다. 필요한 상부철근/지점·스프링 영향도 명시한다.
3. 휨·일방향 전단·최소/분배 철근·위험단면을 KDS로 연결한다. 기존 mechanicsLaw 내력을 최종 KDS로 승격하지 않는다. 실제 기둥 폭/위치·상하부 철근에서 유효깊이를 계산한다.
4. 중심 펀칭을 확장해 편심 모멘트 전달, 가장자리/모서리 임계 둘레, 임계 영역 내 반력 공제·개구부/지원범위·철근 연장과 정착을 검사한다. KDS 식을 확인하지 않고 ACI의 익숙한 편심식을 그대로 대입하지 않는다.

## M6 — 후보 생성부터 적용 후 재계산까지

대상: G20~G22. 진입: M3~M5 실제 검사, M1 완료 정의.

2. 변경 영향 그래프를 따라 연결 부재·접합·기초·전체 안정·하중/강성을 재검토한다. 영향 범위 충족과 프로젝트 충족은 따로 표시한다. 영향 없는 미완료 프로젝트를 숨기거나 영구적인 code-compliance placeholder 때문에 모든 후보가 실패하게 하지 않는다.
3. 실행 전에 허용 변수·제품·상한·목적함수·autoApply 정책을 고정한다. 하중·강도·지반·규칙·고정 영역은 자동 변경하지 않는다. 예비 후보 순위와 적용 가능한 후보를 구분한다.
4. `candidate-evaluated → apply → new identity → reuse/reanalysis → design → comparison → artifacts-ready` 상태를 만든다. 강성 변경은 실제 활성 모델의 새 해석/평가 기록으로 연결한다. 격리 후보 결과를 검증 없이 최종 활성 결과로 복사하지 않는다.
5. 같은 requestId는 중복 모델 변경/작업을 만들지 않는다. 적용 전 실패는 원본 보존, 적용 후 계산 실패는 적용된 변경과 실패 상태를 정확히 남기고 명시 rollback/resume 경로를 제공한다. 뒤늦은 사용자 변경을 rollback으로 덮지 않는다.
