## 개발 방법

- 기존 작업 트리를 보존하고 필요한 변경만 추가한다.
- 각 연결의 결함을 작은 RED로 재현한 후 코드 수정, 영향 있는 선택 시험만 실행한다.
- 이미 입증된 수치 oracle을 이유 없이 반복하지 않는다. 전체 회귀와 실제 건물 시험은 실행하지 않는다.
- 조회·보고서는 준비된 결과를 소비하며 수치 계산을 다시 하지 않는다. WebMCP와 UI는 공통 서비스/결과 식별자를 사용한다.
- 계산 결과에는 적용 KDS 근거와 방법의 적용 범위를 보존한다. 공식 근거 없는 계수나 시점은 추정하지 않는다.
- 각 순서 완료 시 상태 문서·요구사항 대장·evidence·Wiki를 갱신한다. 부분 PASS를 마일스톤 전체 완료로 표시하지 않는다.

## 착수 상태

C1 착수: 기존 장기곡률 경로는 이미 최종 수요/허용값을 계산한다. 보고서가 이를 읽기 쉬운 계산 단계로 보여주는 연결을 먼저 보강한다. 새 프레임 단계 합성의 부착 정책은 아직 별도 잔여다.
