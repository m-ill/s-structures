## 비례 이축 수요 포락 확장 — 2026-09-13

기존 KDS 이축 단면강도 owner에 My/Mz 실제 동시 수요를 전달한다. 비례 이축 범위는 `My(x)=uy*m(x)`, `Mz(x)=uz*m(x)`처럼 고정 단위방향과 하나의 부호 있는 크기로 나타나는 경우이다. 방향이 반전되는 음의 m도 포함한다. `proportionalBending`은 각 수요의 방향 잔차를 확인하고, 크기 오버플로/비유한 값이나 비례하지 않는 수요는 거부한다. 수치 방향 잔차 허용치는 `1e-9*max(1, moment magnitude)`이다.

검증된 회복원본의 각 cubic 구간에서 네 표본의 My/Mz가 같은 방향인지 확인한 뒤 scalar m의 다항식 계수를 계산한다. 3차 이하라는 기존 회복범위 안에서 네 점의 선형종속은 구간 전체의 방향 일치를 확인하는 조건이다. 양끝과 m의 도함수 근에서 실제 두 모멘트를 회복하며, 모든 구간과 경계에서 다시 전역 방향을 확인한다. 고정 N와 고정 방향에서 각 부호의 강도 한계는 같은 기존 단면 owner를 사용하므로 signed extrema로 범위를 검사한다. `polynomialSegments.coefficients`는 이제 `component=signed-proportional-moment`와 `direction`을 함께 기록한다. 순수 Mz 경로는 기존 계수와 같다.

합성 분포하중의 독립식 `My=4x-x²`, `Mz=8x-2x²`에서 x=2의 두 극값 4/8과 회복포락이 일치했다. 방향이 달라지는 분포하중은 거부하고 pure My도 내부 극값을 확인했다. 실제 비례 이축 WebMCP/분포하중 A급/KDS 검토는 `focused-2026-09-12T15-05-02-203Z`, 기존 일축 구간별 하중 회귀는 `focused-2026-09-12T15-05-42-191Z` PASS. 일반 방향변화 이축 및 독립 해석기 비교 완료를 주장하지 않는다.
