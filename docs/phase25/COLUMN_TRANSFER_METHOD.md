# Phase25 기둥–기초 반력 기준점 및 전단 전달

상태: 축압축/순인장 및 축력+전단의 연속 직선 주근 경로 구현·집중 검증. 양축 휨 접촉면은 별도의 제한 응력 평형 모델로 연결했으며 독립 검토가 필요하다. 비틀림·국부 전단 구속/지압 연성·이음/후크/다월 전체는 잔여. Phase25/M5 전체 완료 아님.

## 반력 기준점

- 평면 기준은 `reactionMomentReference`, 높이는 `reactionVerticalReference` (footing-base/footing-top/specified-height). 지정 높이에만 `reactionHeightAboveBase`를 함께 입력한다. 숫자 0은 유효한 저면 높이다.
- 수평 반력이 있는데 높이 기준이 빠지면 `FOOTING_REACTION_HEIGHT_REFERENCE_REQUIRED`. 수평력이 정확히 0이면 높이에 따른 모멘트 변화가 없으므로 기존 입력을 유지한다.
- 기둥 중심 기준 입력의 기초 저면 중심 이동은 외적 r×R: Mx += yRz-hRy, My += hRx-xRz, Mz += xRy-yRx. 평면 모멘트가 이미 기초 중심 기준이면 x/y 이동은 추가하지 않는다. 높이 이동은 별도로 수행한다.
- 자중 포함 반력은 입력 반력 자체를 옮기고, 기초 중심의 균등 분포 하중을 분리해 기둥 단독 N/M을 구한다. 중복 자중 모멘트를 더하지 않는다.
- 토압/기초 절단면은 저면 기준 totalMx/My, 내부 펀칭은 columnBaseMx/My, 기둥 전달 검사는 기초 상면 기준 columnMx/My/Mz를 사용한다. `footing-top` 높이는 두께 후보가 바뀌면 새 두께를 따른다.
- 저면 totalMz가 미확정 또는 0이 아니면 단순 병진 마찰만으로 활동 OK를 반환하지 않는다. 병진만으로 이미 NG인 경우 NG를 보존하고 비틀림 분포 미검토를 함께 기록한다.

## 압축+전단 접촉면

기존 `cast-in-place-continuous-straight-bars` 경로를 확장한다. 수직·직사각형 기둥, 직교 축, 단일 부재 대응, 연속 무도막 주근, 이음 없음, 보통 콘크리트가 전제다. 접촉면의 Mx/My/Mz가 0인 축압축/순인장/축력+전단을 처리한다. 순인장 경로는 철근 면적 도심이 기둥 중심과 일치해야 한다. 휨이나 비틀림이 있으면 이 경로의 결과를 확대 적용하지 않는다.

- `columnInterfaceSurface`: monolithic / roughened-6mm / unroughened.
- 경화 후 타설면은 `columnInterfaceClean=true`와 `columnInterfacePreparationReference`가 필요하다. 일체 타설도 시공면 근거는 기록한다. 입력은 현장 시공 품질의 독립 확인을 대체하지 않는다.
- KDS 14 20 22 4.6.2(1), 식 4.6-1: Vn=Avf·fy·μ. 보통 콘크리트 μ=1.4/1.0/0.6, 전단마찰 설계 fy는 최대 500MPa다. 영구 압축력에 의한 추가 마찰 저항은 인정하지 않는다.
- 일체/6mm 거친 면의 명목 응력 상한은 min(0.2fck,3.3+0.08fck,11) MPa, 비거친 면은 min(0.2fck,5.5) MPa다. 서로 다른 두 콘크리트 중 낮은 강도를 사용하며 φ=0.75를 적용한다.
- 전체 축압축은 확대 지압이나 철근 분담 없이 콘크리트 지압으로 확인한다. 연속 주근 최소량 0.005Ag를 확인한다. 접촉면 전단을 받는 주근은 양쪽에서 **인장 항복 정착**을 확인하며 압축 정착 길이로 대신하지 않는다.
- 정착은 실제 주근 중심 간격/기둥 표면·기초 외곽 거리와 Ktr=0을 사용한다. 수직 철근의 top-bar 계수는 적용하지 않는다. 매입 길이의 기초 두께/피복 한계와 상부 연속길이의 실제 배근 구간 한계도 검사한다.
- `columnEmbedmentLength`, `columnDevelopmentAbove`를 기초/종속 기초 후보에 추가했다. 실제 WebMCP 후보 적용·재해석·재검토가 변경된 길이와 높이를 사용한다. 자동으로 표면 조건이나 지반 성능을 높이지 않는다.

대표 ratio/demand/capacity/unit은 같은 지배 조건을 표시한다. 지압, 최소 철근, 양쪽 정착, 배치 길이 한계, 전단마찰을 `criteria`에 분리하고 `governingCriterion`을 기록한다. 축력/지압 내력은 columnCompressionDemand/bearingCapacity에 보존한다.
