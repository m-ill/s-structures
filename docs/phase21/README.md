## 목표와 개발 순서

**첫 구현은 강체 다이어프램이 있는 골조의 Direct P-Delta 지원이다.** 이후 3층 상가주택 실무시험에서 확인한 RC 단면 오류, 입력·결과 연결 오류, 보고서 집계·출처 누락을 수정한다. 해석부터 화면·WebMCP·보고서 저장까지 같은 결과를 추적하고, 반복 작업과 중단·복구에도 수치와 자료를 보존하는 것이 이번 Phase의 목표다.

기존 최신 개발 문서는 [Phase 20](../phase20/README.md)이다. Phase 20의 M0~M5 완료와 배포 기록은 보존하고, 후속 번호를 **Phase 21**로 부여한다. Phase 20의 112개 회귀 통과가 새 실무 경로의 무결함을 뜻하지 않는다. 이번 Phase의 최종 후보에서 기존 회귀와 신규 재현 시험을 다시 실행한다.

## Phase 21의 지원 범위

### 이번에 완성할 범위

1. 기존 수평 XY 강체 다이어프램의 소변형 구속 `ux/uy/rz`를 사용하는 3D 프레임 Direct P-Delta. `uz/rx/ry`는 기존 부재·지점 계약을 따른다. 층 전체를 6자유도 강체로 바꾸지 않는다.
2. 지원 입력에서 CPU f64 동기 및 제품 Worker 경로의 동일 수치 계약. 비동기·hybrid 경로도 같은 구속을 적용하거나, 미검증 조합을 실행 전에 명시적으로 차단한다.
3. RC 예비 검토의 치수·축·역할·입력 검증과 결과 의미 정정. 계산이 예비식이면 UI·WebMCP·보고서에서도 예비식으로 표시한다.
4. 읽기와 변경, 요청 조합과 포락, 성공과 설계 사용 자격, 완전한 원본과 파생/부분 파일을 일관되게 구분한다.
5. 실측으로 정한 규모에서 반복 실행·큰 보고서·취소·재시작을 견디는 자원 관리. 측정하지 못한 M/L 규모나 GPU 메모리에는 지원 자격을 부여하지 않는다.

### 별도 검증을 유지할 범위

Direct의 release, 0강성 회전 연결, 인장/압축 전용 부재의 active set, 기울어진 다이어프램, 큰 회전·재료 비선형, semi-rigid/shell과의 혼합을 강체 지원 완료에 묶어 자동 허용하지 않는다. 기존 지원 경로를 보존하고 조합별 capability 시험으로 회귀를 막는다. 중력 접선강성을 소비하는 prestressed modal/RSA도 영향 검사를 수행하며 별도 수치 검증 전까지 지원 범위를 확장하지 않는다.

배근 상세·규준별 P-M-M·전단철근 Vs·접합부·슬래브·기초 전체 설계는 이번 결함 수정만으로 완성되지 않는다. 해당 검토의 적용범위와 미검토 사유는 결과에 남긴다. 주소와 용도만으로 인허가·지반·건축계획까지 확정하는 기능도 이번 범위가 아니다.

## 공개와 생산 자격

소프트웨어의 수치·복구·자원 gate와 실제 구조설계의 독립 검토 gate를 각각 기록한다. 외부 비교 2건, pilot 5건, 적용 규모의 성능 자격 및 독립 검토는 [Phase 19 검토 인계](../phase19/REVIEW_INTAKE.md)를 따른다. 독립 검토 담당은 기존 사용자 답변대로 **사용자**다. 현재 상가주택 1건이나 기존 21개 벤치마크를 그 요건 전체의 대체 증거로 세지 않는다.

M7은 조건이 충족된 범위의 개발 프리뷰 패키징·배포까지 마감할 수 있다. 미충족 외부 조건을 그대로 명시하며, `production-qualified` 또는 최종 설계 전달 허용으로 승격하지 않는다. 이번 계획 작성 자체에는 제품 수정·테스트 실행·push·배포가 포함되지 않는다.

## Phase 21 이후 후보

Phase 21의 검증 결과로 다음 범위를 확정한다. 아직 Phase 22 구현을 시작하거나 완료 일정을 약속하지 않는다.

- **RC 실설계 완성:** 실제 배근·유효깊이, 규칙 버전이 고정된 P-M-M/전단철근/상세, 접합부·슬래브·기초의 검토 범위와 독립 비교.
- **Direct 조합 확장:** release 및 유한 회전스프링의 Ke+Kg 일관 응축, unilateral active set, semi-rigid/shell 혼합. 각 기능의 해법·복원·안정성 검증이 선행돼야 한다.
- **대규모 해석:** M/L 계측에서 병목으로 확인된 희소 구속 축약·분해·결과 저장의 확장. 단순 캐시 증설로 지원 규모를 늘리지 않는다.
- **실무 자격:** 사용자 제공 외부 2건·pilot 5건과 실제 설계조건을 결속한 최종 자격 검토.
