# 공개 개발판 배포 정책 — 2026-09-13

사용자 요청에 따라 GitHub Pages에서 main의 최신 개발 기능을 제공한다.
배포 성공은 공학적 적합성 인증이나 실무 설계 승인에 해당하지 않는다.

- 필수 조건: 현재 커밋의 정적 파일·의존성·폰트 무결성 빌드, WebMCP 보안·조회/실행 연결, 설계 작업 흐름, UI 배치·리본·부착 시점 판정 UI의 선택 회귀 검사 통과.
- `tools/check-pages-preview.mjs`의 어느 검사라도 실패하면 배포를 차단한다. 빌드 실패도 차단한다.
- 과거 Phase21 release gate는 별도 참고 감사로 실행하여 실제 결과를 Actions 요약에 남긴다. 과거 BLOCKED 또는 PENDING을 PASS로 바꾸지 않는다.
- 전체 회귀는 기존 Verify 워크플로에서 계속 수행한다. 종합 검증·전체 메모리·외부 비교·독립 검토의 미완료 상태는 별도로 유지한다.
- 메뉴에 개발 공개판 상태를 표시하며, 배포물의 `RELEASE-STATUS.json`과 `SOURCE-IDENTITY.json`으로 채널·적합성 미확립·정확한 커밋을 확인한다.
- 결과별 KDS 근거, 미검토 사유, 설계 전달 가능 조건과 계산 모듈은 변경하지 않는다.

GitHub Pages는 브라우저 정적 앱이다. 기존 서버 전용 영속 저장 및 서버 API가 자동으로 호스팅되는 것은 아니다. 브라우저 지원 기능과 파일 저장·복원 경로를 사용한다.

필요 시 이전 정상 커밋을 revert하여 동일 필수 검사를 거쳐 다시 배포한다. 검증 미완료 사항은 Phase25 검증 인계 문서에서 관리한다.

## 알려진 문제 — 2026-09-13 코드 리뷰

지점에 연결된 일반 MPC의 반력 전달과 평형 판정에 미해결 문제가 있다. 고정점에 직접 연결한 MPC는 평형 FAIL, 중간 절점을 거친 연결은 지점 반력 0인데 PASS가 되는 작은 모델을 재현했다. 따라서 해당 연결의 PASS를 반력·평형 검증 완료로 해석하면 안 된다. 구속 반력 회복과 공유 DOF 그룹 처리를 보완하고 직접·연쇄 연결의 회귀 검증을 추가해야 한다. 이번 공개 개발판 배포는 이 문제를 해결했다는 의미가 아니다.
