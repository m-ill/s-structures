## 자료와 인증

사용자가 제공한 승인 API 인증으로 KCSC의 CodeViewer 응답 9건을 확보했다. [공식 API 안내](https://www.kcsc.re.kr/support/api)를 출처로 사용했다. 인증키는 대화에서 전달받아 로컬 취득 도구의 비표시 표준입력으로만 사용했으며 소스·문서·manifest에 기록하지 않았다. Pages/브라우저 번들에는 인증키나 인증 요청 경로를 넣지 않는다.

- 취득 도구: `tools/fetch-p24-kcsc.py`. 고정 공식 HTTPS 도메인, 응답 20MiB/25초 제한, 문서 코드·판본·조항 목록 검증, 인증값 반사 응답의 저장 거부. 오류는 URL 대신 유형만 출력한다.
- 원문: `verification/evidence/phase24/kcsc/KDS-*-official.json`.
- 취득 시각·SHA-256·크기·인증값 없는 출처: 같은 폴더의 `retrieval-manifest.json`.
- 제품 조회용 메타데이터: `src/metadata/kcscRuleSources.js`. 원문 HTML·이미지를 런타임에 적재하지 않는다.
- 공식 API는 수식을 GIF 이미지로 제공한다. 텍스트 변환에서 사라진 수식을 기억으로 채우지 않는다. 정착식 이미지와 검토용 합성 캡처를 evidence에 보존했다.

## 이번 계산 연결

`kdsAnchorage.js`는 mm/MPa 단위로 4.1.2 직선 인장, 4.1.3 압축, 4.1.5 표준후크 요구 정착길이, 4.5.2 인장 겹침이음 길이를 계산한다. sqrt(fck) 상한, 경량계수, 상부철근/도막, 보정계수 곱 상한, c와 Ktr, 고강도 횡구속 조건, 조항별 최소길이를 적용했다. 임의 잉여철근·구속 저감은 적용하지 않는다.

실제 배근 경로는 단일 이형철근·직사각형 단면에서 저장된 좌표/직경/철근 재료로 c를 계산한다. Ktr는 보수적으로 0을 사용한다. 정착 형식·콘크리트 종류·타설 위치·도막·겹침 필요 여부를 공통 입력 schema에 추가해 UI/WebMCP preview/apply/get 경로로 전달한다. 제공 길이와 비교해 OK/NG를 반환한다. 제품의 인장 겹침은 B급만 지원한다. A급 순수 함수는 제공/소요 면적비와 동시 이음 비율 근거가 필요하다.

후크 요구길이 계산만으로 실제 후크가 배치됐다고 판단하지 않는다. 후크 형상/배치 미확정, 압축 이음, 다발/머리철근, 서로 다른 지름의 이음, 영역 단부별 정착 상세는 후속 구현 대상이다. 전체 `rc-code-compliance`와 설계 전이 차단은 유지한다.

기존 `rc/rebar.js`의 0.043 계수·추가 1,000 배율 경로를 공식 함수 어댑터로 교체했다. 과거 D19/fck27/fy400은 조건 없이 63,224mm를 출력했다. 이제 조건 누락/알 수 없는 철근은 길이 null·NOT_CHECKED다. 명시적 λ1/c50mm/Ktr0/보통 위치/무도막/D19/fck25/fy400 예제는 인장 441mm, B급 이음 573mm(최종 mm 올림)다. 이음 배율을 적용하기 전에 정착 300mm 하한을 제외하는 조건도 시험했다.

## 기초·결과 관리 보강

- 이축 부분 접촉: `q=max(0,a+b*x+c*y)` 압축 전용 접촉 영역과 힘/모멘트 평형을 구한다. 영역 다각형의 정확 적분과 정규화 좌표를 사용한다. 반복수 80, 선형검색 및 수렴 실패 사유가 있다.
- 같은 접촉 압력장을 기둥 면 휨 및 d만큼 떨어진 일방향 전단 단면에 적분한다. 삼각형 q=300(x+y), N400kN, 편심 각각0.5m의 독립 예제로 qmax600kPa/면적2m² 및 반쪽 적분350kN/212.5kNm와 대칭성을 확인했다.
- 기초 자중 범위와 서비스/강도 반력 구분은 유지한다. 이 변경은 뚫림전단·지반 적합성·역방향 휨 상세까지 완성했다는 뜻이 아니다.
- 동일 입력·source hash·역학 law의 평가를 재호출하면 단면 계산 전에 유효성을 확인하고 저장 평가를 재사용한다. evaluator 버전을 평가 ID에 포함한다. 이전 규칙 버전의 평가/후보는 현재 결과로 적용하지 않는다.

## 후속 4차 계산·결과 계약 (2026-09-11)

모든 새 canonical 검토 행에 `codeBasis`를 저장한다. 검토 결과·후보·UI·WebMCP·JSON·CSV·HTML·PDF에서 같은 근거를 사용한다. `CLAUSE_APPLIED`는 공식 metadata와 코드/판본/URL/SHA256이 일치하고 조항이 있는 계산에만 부여한다. 미검토/입력 누락은 참고할 조항이 있어도 `NOT_ESTABLISHED`다. 철골 예비식과 기본 층간변위 한계에는 KDS 적용을 임의 부여하지 않는다. 조회/보고서 렌더링은 저장 근거를 표시하며 새 계산을 하지 않는다. 개별 조항 적용과 전체 KDS 적합성은 다르며 wholeDesignQualified는 false다.

- M4: KDS 14 20 20:2022 4.1.1/4.1.2 응력블록과 축력/2축휨, 14 20 10:2021 4.2.3의 변형률별 φ. 고강도 표의 중간값은 근거 미확정으로 보류한다.
