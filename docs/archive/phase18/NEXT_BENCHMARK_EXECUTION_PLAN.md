# 다음 벤치마크 실행 계획

## 목적

P18 엔진 준비 결과를 실제 STRIX·MIDAS 동일모델 수치 비교로 승격한다. 입력이 잠기기 전에는 공식 PASS를 발행하지 않는다.

## 권장 순서

1. **SR1 입력 잠금**: CSI 원문에서 질량, 단면, 8요소 연결, 스펙트럼 표를 확보하고 SHA-256 source lock을 만든다.
2. **SR1 동일모델 실행**: S-Structures canonical model, 모드별 참여질량, SRSS/CQC, 층변위, 부재모멘트를 한 패키지로 고정한다.
3. **SR2 입력 잠금·실행**: 편심 CM, 6-DOF 질량, 강체격막, 네 모달조합, roof CM 응답을 비교한다.
4. **SR2b 입력 잠금·실행**: L형 좌표, 84개 부재번호, El Centro 표를 잠그고 가새 축력 부호까지 비교한다.
5. **SB12 제품 통합**: 일반 정적 해석 결과에 링크 기본변형·기본력·단부력을 노출한다.
6. **SH1 제품 통합**: 전역 PMM 도메인을 증분 Newton 반복과 상태 commit/revert에 연결하고 cyclic·restart 시험을 통과시킨다.
7. **외부 교차검증**: 사용자가 보유한 MIDAS/STRIX 실행 결과와 동일 입력 해시를 대조한 뒤 프로그램별 오차표를 만든다.

## 문제별 완료 조건

- 원문·모델·스펙트럼·단위·부호의 source lock
- S-Structures 입력과 원문 입력의 필드별 equivalence 표
- 생산 엔진 actual solve 3회와 결정론적 result projection hash
- 독립 이론해 또는 제3 solver 결과와 수치 오차
- 평형·에너지·질량직교·참여질량 등 물리 불변량
- 문제 폴더의 모델, 실행로그, 원시결과, 그림, Markdown/PDF 보고서
- 외부 PASS는 실행 프로그램·버전·입력 해시·결과 원본이 모두 있을 때만 판정
