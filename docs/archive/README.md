# 과거 Phase 자료

Phase 2~24 및 post-phase5의 계획·결정·구현 기록을 보관한다. 문서에 쓰인 active/next/complete는 작성 당시 상태다.
현재 개발은 [Phase25](../phase25/README.md), 사용 방법은 [사용자 설명서](../user-manual/README.md)를 확인한다.

2026-09-13 정리에서 문서 393개를 이곳으로 이동하고 활성 테스트·문서·Wiki의 참조 경로를 갱신했다.
검증 evidence 내부 원래 경로와 소스 해시는 역사 기록이므로 변경하지 않았다. 해당 경로는 기록된 소스 커밋에서 해석해야 한다.
현재 실행 코드, 회귀 테스트, verification 근거는 개발 저장소에 보존하며 독립 실행 패키지에서는 제외한다.
