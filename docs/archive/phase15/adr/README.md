# Phase 15 Architecture Decision Records

Phase 15 구현 중 공학 의미·호환성·수치 경로를 장기적으로 고정해야 하는 결정만 ADR로 작성한다.

예정 ADR:

| ID | 결정 |
| --- | --- |
| ADR-001 | canonical sparse assembler와 SPD fallback policy owner |
| ADR-002 | plate soft/hard/clamped boundary semantics와 legacy migration |
| ADR-003 | Winkler structural/foundation/equilibrium end-action 계약 |
| ADR-004 | calculation/result/run-record hash와 stale policy |
| ADR-005 | unsupported rotation classifier와 physical null-mode 보호 |

ADR에는 context, alternatives, decision, numerical/compatibility consequences, migration, rollback, affected requirements/tests와 reviewer를 포함한다. 계획 단계에서는 결정을 선점하지 않고 P15-M0~M2 review에서 확정한다.
