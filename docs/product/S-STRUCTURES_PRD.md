# S-Structures Product Requirements Document

문서 버전: 0.1  
작성일: 2026-06-24  
제품명: S-Structures  
제품 방향: 웹 기반 직접 매트릭스 구조해석 및 건축구조 탄성설계 도구  
핵심 제약: OpenSees, 상용 해석엔진, 외부 네이티브 솔버에 의존하지 않는다.

## 1. 제품 개요

S-Structures는 브라우저에서 바로 실행되는 건축구조 해석 및 설계 도구다. 초기 제품은 3D 프레임 직접강성법을 기반으로 선형 탄성해석, 하중조합, 부재력 포락, 기초적인 철골/RC 설계검토를 제공한다. 장기적으로는 고유치해석, 응답스펙트럼해석, P-Delta, 소성힌지 기반 비선형 pushover까지 자체 구현한다.

이 제품은 기존 복원 코드의 기능 범위와 데이터 구조를 참고하되, 그 복원본의 OpenSees 기반 해석엔진이나 설계엔진을 이식하지 않는다. S-Structures는 독립적인 웹 구조해석 엔진을 보유하는 것을 목표로 한다.

## 2. 제품 비전

건축구조 엔지니어, 연구자, 학생이 별도 설치 없이 웹에서 구조 모델을 만들고, 탄성해석과 기본 설계검토를 즉시 수행할 수 있게 한다.

장기 비전은 다음과 같다.

- 실무 초기 검토에 충분한 3D 프레임 구조해석
- 구조설계 공식과 계산 흐름이 투명한 웹 기반 엔진
- 교육, 검산, 대안 비교에 강한 인터랙티브 구조해석 도구
- 상용 프로그램 결과를 맹신하지 않고 직접 검증할 수 있는 lightweight design checker
- 향후 비선형 거동 학습 및 연구용으로 확장 가능한 자체 알고리즘 기반 플랫폼

## 3. 배경 및 문제 정의

현재 S-Structures는 단일 HTML 기반으로 3D 프레임 모델링과 단순 탄성해석을 제공한다. 그러나 건축구조 설계 도구로 성장하려면 다음 문제가 해결되어야 한다.

- UI, 모델 데이터, 해석 로직, 결과 표시가 강하게 결합되어 있다.
- 구조 모델 스키마가 장기 확장에 충분히 엄격하지 않다.
- 하중케이스, 하중조합, 포락, 설계검토의 데이터 흐름이 제품 수준으로 정리되어 있지 않다.
- 검증 예제와 회귀 테스트가 부족하다.
- 비선형해석으로 확장할 수 있는 해석 상태, 요소 상태, 반복해석 구조가 아직 없다.
- 설계 공식과 코드 기준을 체계적으로 관리할 문서/테스트 구조가 없다.

따라서 첫 목표는 "기능 추가"가 아니라 "제품 구조 재정렬"이다.

## 4. 사용자 및 사용 시나리오

### 4.1 주요 사용자

1. 구조설계 실무자
   - 초기 골조 검토, 부재력 흐름 확인, 하중조합별 지배 부재 확인이 필요하다.
   - 상용 프로그램을 열기 전 빠르게 개략 모델을 만들고 싶다.

2. 건축구조 연구자
   - 직접강성법, P-Delta, pushover 알고리즘을 투명하게 확인하고 싶다.
   - 알고리즘 수정과 검증 예제 추가가 쉬운 도구가 필요하다.

3. 구조공학 학생
   - 매트릭스 구조해석의 결과를 시각적으로 이해하고 싶다.
   - 보, 포털프레임, 3D 골조의 변위와 부재력을 직접 비교하고 싶다.

4. 개발자/제작자
   - 웹 기반 구조해석 엔진을 모듈화하고 확장하고 싶다.
   - 상용 구조계산 프로그램 수준의 기능 범위를 장기적으로 자체 구현하고 싶다.

### 4.2 핵심 사용자 여정

1. 사용자는 웹 페이지를 연다.
2. 예제 모델 또는 빈 프로젝트를 선택한다.
3. 층, 그리드, 노드, 부재, 단면, 재료를 입력한다.
4. 지점조건과 하중케이스를 입력한다.
5. 하중조합을 생성하거나 직접 편집한다.
6. 선형 탄성해석을 실행한다.
7. 변위, 반력, 부재력, 다이어그램을 확인한다.
8. 부재별 설계검토 결과와 검토비 컬러맵을 확인한다.
9. JSON 프로젝트와 PDF/HTML 보고서를 저장한다.

## 5. 제품 원칙

- 브라우저 우선: 설치 없이 기본 기능이 작동해야 한다.
- 직접 구현: 핵심 해석 및 설계 알고리즘은 자체 코드로 구현한다.
- 투명성: 결과 수식, 하중조합, 지배 조합, 지배 위치를 사용자가 추적할 수 있어야 한다.
- 검증 가능성: 모든 핵심 기능은 손계산 예제 또는 기준 예제와 비교되어야 한다.
- 점진적 복잡도: 단순 선형해석부터 시작하고, 동적해석과 비선형해석은 단계적으로 확장한다.
- 모델 중심: UI는 바뀌어도 모델 스키마와 해석 API는 안정적으로 유지한다.
- 교육 친화성: 계산 과정을 숨기지 않고, 해석 단계별 상태를 확인할 수 있게 한다.

## 6. 범위

### 6.1 포함 범위

- 3D 프레임 직접강성법
- 노드 6자유도 기반 선형 탄성해석
- 보/기둥/브레이스 모델링
- 재료/단면 라이브러리
- 지점조건, 부재 릴리즈, 강체 offset
- 절점하중, 부재분포하중, 부재집중하중
- 하중케이스, 하중조합, 결과 포락
- 변위, 반력, 부재력, 다이어그램 시각화
- 철골 기본 설계검토
- RC 기본 설계검토
- JSON 저장/불러오기
- 계산서/보고서 출력
- 고유치/RSA/P-Delta/pushover의 단계적 자체 구현

### 6.2 제외 범위

초기 제품에서 제외한다.

- OpenSees 연동
- MIDAS, ETABS, SAP2000 API 연동
- 정밀 유한요소 판/쉘 해석
- 완전한 KDS/ACI/AISC 전 조항 자동 검토
- 철근 상세도 자동 생성
- 시공도면 수준의 CAD 편집기
- 대규모 클라우드 협업
- 인증된 최종 구조계산서 대체

## 7. 제품 기능 요구사항

### 7.1 프로젝트 관리

요구사항:

- 사용자는 새 프로젝트를 생성할 수 있어야 한다.
- 사용자는 예제 프로젝트를 열 수 있어야 한다.
- 사용자는 프로젝트를 JSON으로 저장하고 다시 불러올 수 있어야 한다.
- 프로젝트에는 `schemaVersion`, 단위계, 작성일, 수정일, 제품 버전이 포함되어야 한다.
- 오래된 프로젝트는 migration 과정을 거쳐 최신 스키마로 변환되어야 한다.

수용 기준:

- 저장 후 다시 열었을 때 모델, 하중, 결과 설정이 유지된다.
- 스키마 버전이 다른 파일을 열면 migration 로그가 표시된다.
- 잘못된 JSON 파일은 구조화된 오류 메시지를 표시한다.

### 7.2 모델링

요구사항:

- 사용자는 노드, 부재, 단면, 재료를 생성/수정/삭제할 수 있어야 한다.
- 사용자는 층과 그리드를 정의하고 반복 골조를 빠르게 생성할 수 있어야 한다.
- 사용자는 보, 기둥, 브레이스 타입을 지정할 수 있어야 한다.
- 사용자는 지점조건을 6자유도별로 지정할 수 있어야 한다.
- 사용자는 부재 릴리즈와 offset을 지정할 수 있어야 한다.
- 사용자는 부재 그룹, 층 그룹, 선택 세트를 관리할 수 있어야 한다.

수용 기준:

- 3층 2경간 포털프레임을 5분 이내에 작성할 수 있다.
- 노드와 부재를 삭제했을 때 참조 무결성 오류가 발생하지 않는다.
- 모델 검증 단계에서 고립 노드, 무단면 부재, 무재료 부재, 길이 0 부재를 감지한다.

### 7.3 단면 및 재료

요구사항:

- 기본 재료 프리셋을 제공한다.
  - Steel SS275, SM355
  - Concrete 24 MPa, 27 MPa, 30 MPa
  - User-defined material
- 기본 단면 타입을 제공한다.
  - H형강
  - 각형강관
  - 원형강관
  - 직사각형 RC
  - 원형 RC
  - 사용자 정의 일반 단면
- 단면은 해석 속성과 설계 속성을 분리해서 보유해야 한다.
  - 해석 속성: A, Iy, Iz, J, Avy, Avz
  - 설계 속성: depth, width, flange/web thickness, Z, S, r, compactness data

수용 기준:

- 단면을 바꾸면 해석 결과가 갱신된다.
- 사용자 정의 단면도 해석에 사용할 수 있다.
- 설계검토에 필요한 속성이 부족하면 명확한 경고가 표시된다.

### 7.4 하중

요구사항:

- 절점하중을 6성분으로 입력할 수 있어야 한다.
- 부재하중을 local/global 방향으로 입력할 수 있어야 한다.
- 부재하중 타입은 균등분포, 집중하중, 사다리꼴 하중을 지원한다.
- 하중케이스는 타입을 가져야 한다.
  - D, L, W, E, R, S, User
- 자중 자동 반영 옵션을 제공한다.
- 하중 표시와 해석 적용값이 일치해야 한다.

수용 기준:

- 균등분포하중을 가진 단순보의 반력과 최대모멘트가 손계산과 일치한다.
- local 방향 하중과 global 방향 하중이 구분되어 결과에 반영된다.
- 하중케이스별 on/off 표시가 가능하다.

### 7.5 선형 탄성해석

요구사항:

- 3D 프레임 요소의 12x12 local stiffness matrix를 사용한다.
- 각 노드는 6자유도를 가진다.
- 좌표변환행렬을 사용해 local stiffness를 global stiffness로 변환한다.
- 전체 강성행렬을 조립하고 경계조건을 적용한다.
- 해석 후 전체 변위, 반력, 부재단력, 위치별 단면력을 산출한다.
- 해석 실패 원인을 사용자에게 표시한다.

수용 기준:

- 캔틸레버, 단순보, 포털프레임, 3D 프레임 검증 예제에서 허용오차 이내 결과를 낸다.
- 불안정 구조는 특이행렬 오류로만 끝나지 않고, 의심 노드/자유도를 표시한다.
- 해석 결과는 UI 없이 API 호출로도 얻을 수 있다.

### 7.6 하중조합 및 포락

요구사항:

- 사용자는 하중조합을 직접 만들 수 있어야 한다.
- 기본 조합 템플릿을 제공한다.
- 조합별 변위, 반력, 부재력을 계산한다.
- 부재별 지배 조합과 지배 위치를 저장한다.
- 축력, 전단력, 휨모멘트, 비틀림에 대한 최대/최소 포락을 제공한다.

수용 기준:

- 각 부재에서 `max Mz`, `min Mz`, `max My`, `max P`, `max V`의 지배 조합을 확인할 수 있다.
- 포락 결과가 설계검토 입력으로 연결된다.
- 하중조합 계수를 바꾸면 포락과 설계결과가 갱신된다.

### 7.7 결과 시각화

요구사항:

- 3D 모델 뷰를 제공한다.
- 변형 형상을 확대 배율과 함께 표시한다.
- 축력도, 전단력도, 모멘트도를 표시한다.
- 반력 벡터와 하중 벡터를 표시한다.
- 부재별 검토비 컬러맵을 표시한다.
- 결과 테이블을 제공한다.

수용 기준:

- 결과 표시가 모델 형상과 겹쳐도 읽을 수 있게 스케일 조절이 가능하다.
- 사용자는 하중케이스/조합/포락 모드를 전환할 수 있다.
- 선택한 부재의 상세 결과가 패널에 표시된다.

### 7.8 탄성설계

요구사항:

- 1단계 설계는 "최소 실용 설계검토"로 정의한다.
- 철골 보 검토:
  - 휨
  - 전단
  - 처짐
  - 횡좌굴 입력값 기반 경고
- 철골 기둥 검토:
  - 압축
  - 휨-압축 조합
  - KL/r
  - 좌굴길이계수 입력
- RC 보 검토:
  - 휨 요구철근량
  - 전단 요구철근량
- RC 기둥 검토:
  - 축력-휨 개략 상관 검토
- 공통:
  - 검토비
  - 지배 조합
  - 지배 위치
  - OK/WARN/NG

수용 기준:

- 모든 설계결과는 입력값, 수식명, 지배 부재력, 지배 조합을 추적할 수 있다.
- 설계공식이 미구현된 항목은 임의로 OK 처리하지 않는다.
- 결과 리포트에 검토 범위와 제외 범위가 명시된다.

### 7.9 고유치 및 RSA

요구사항:

- 질량행렬을 구성한다.
- 집중질량 기반 고유치해석을 수행한다.
- 모드형상, 주기, 참여질량을 산출한다.
- 응답스펙트럼 함수를 입력할 수 있어야 한다.
- SRSS 및 CQC 조합을 지원한다.
- RSA 결과를 설계 포락에 연결한다.

수용 기준:

- 전단건물 벤치마크 예제에서 고유주기가 허용오차 이내로 계산된다.
- 참여질량비가 방향별로 표시된다.
- RSA 결과와 정적해석 결과가 동일한 결과 테이블 구조에 담긴다.

### 7.10 P-Delta

요구사항:

- 기하강성행렬 기반 P-Delta 또는 반복 증폭 방식 중 하나를 먼저 구현한다.
- P-Delta on/off 결과를 비교할 수 있어야 한다.
- 수렴 실패와 안정성 경고를 표시한다.

수용 기준:

- 단순 기둥 및 포털프레임 예제에서 횡변위 증가 경향이 검증된다.
- P-Delta 결과는 설계검토에 사용할 수 있는 별도 해석 결과로 저장된다.

### 7.11 비선형 Pushover

요구사항:

- 초기 범위는 lumped plastic hinge 기반 비선형 정적해석으로 제한한다.
- 부재 중앙부는 탄성 프레임 요소로 유지한다.
- 부재 양단에 회전힌지를 배치한다.
- moment-rotation backbone을 입력할 수 있어야 한다.
- 증분하중 방식과 displacement control을 지원한다.
- Newton-Raphson 반복과 수렴판정을 구현한다.
- capacity curve를 표시한다.
- 힌지 발생 순서와 성능 상태를 표시한다.

수용 기준:

- 단순 포털프레임에서 pushover 곡선이 생성된다.
- 수렴 실패 시 실패 스텝과 원인을 표시한다.
- 비선형 결과는 탄성설계 결과와 혼동되지 않게 별도 탭에 표시한다.

## 10. 성공 지표

초기 성공 지표:

- 검증 예제 20개 이상
- 선형해석 주요 예제 오차 1e-6에서 1e-3 범위 관리
- 3층 2경간 골조 모델링 5분 이내
- 100개 부재 모델 선형해석 1초 이내
- 1,000개 부재 모델 선형해석 5초 이내 목표
- 해석 실패 시 원인 메시지 제공률 90% 이상

제품 성공 지표:

- 사용자가 저장한 JSON 프로젝트를 버전 업 후에도 열 수 있음
- 부재별 검토비, 지배 조합, 지배 위치를 추적 가능
- 보고서에 해석/설계 범위와 제한사항이 자동 표기됨

## 11. 리스크

주요 리스크:

- 직접 구현 고유치/RSA/비선형해석의 수치 안정성 확보가 어렵다.
- 브라우저 메모리와 성능 한계가 대형 모델에서 문제가 될 수 있다.
- 설계기준 구현 범위가 커지면 검증 비용이 급격히 증가한다.
- UI가 복잡해지면 현재 S-Structures의 가벼움이 사라질 수 있다.
- 단위계 혼선은 해석 오류의 가장 큰 원인이 될 수 있다.

대응:

- 선형해석 검증을 완료하기 전 비선형 기능을 시작하지 않는다.
- 단위계는 내부 표준을 하나로 고정한다.
- 설계검토는 "지원 범위"와 "미지원 범위"를 명확히 표시한다.
- 대형 모델 성능 최적화는 dense matrix 이후 sparse matrix 단계에서 수행한다.

## 13. 최종 제품 판단 기준

S-Structures가 다음 조건을 만족하면 "자체 웹 구조해석/설계 도구"의 1차 제품 단계에 도달한 것으로 본다.

- 사용자는 브라우저에서 3D 골조를 모델링할 수 있다.
- 사용자는 설치 없이 선형 탄성해석을 수행할 수 있다.
- 사용자는 하중조합과 포락 결과를 확인할 수 있다.
- 사용자는 부재별 검토비와 지배 조합을 확인할 수 있다.
- 사용자는 결과를 저장하고 보고서로 출력할 수 있다.
- 개발자는 검증 예제로 해석 정확도를 회귀 테스트할 수 있다.
- 제품은 OpenSees 없이 자체 알고리즘으로 작동한다.
